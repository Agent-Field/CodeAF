    ▏ if ./run_report.sh TARGET.csv EXPORT.csv --month 2026-10 --category FOOD --csv --strict; then
    ▏     import TARGET.csv          # exit 0 => written this run, complete for the month
    ▏ else
    ▏     rc=$?                       # capture before anything else
    ▏     echo "no import: report refused (exit $rc)" >&2
    ▏     exit "$rc"                  # preserve status so cron reports the failure
    ▏ fi

  Exit 0 is the only importable state; every non-zero exit skips the import and leaves the                                                 ❮
  previous target in place.

  Demonstrated locally (no external service; touch imported.marker stood in for the
  importer):

  · Failure — export had a rejected inf row: run_report.sh exited 2, the wrapper printed
    no import: report refused (exit 2), the wrapper exited 2, the marker was not created,
    and target.csv kept its old OLD-STALE contents.
  · Success — clean export: wrapper exited 0, marker created, target replaced with
    category,amount / food,42.50 / TOTAL,42.50.

  So rc=$? sits on the first line of the else branch, before any other command, and exit
  "$rc" hands that 2 (or 1, or 64) back to cron.
