=== aforge do --help (stdout only)
  aforge do   "<task>" [--db path] [--keep] [-w dir] [--timeout 900] [--json] [--yes-spend] [--model slug] [--plan-model slug]
                       [--context-fill 60] [--completion-reserve 65536] [--debug]
                         do one task and exit — the same living brain the chat runs, with nobody watching
                         the task is run verbatim: what you type is the goal, and what it has to assume it declares
                         exit 0 the whole of it stands · 1 nothing usable · 2 partial: the wall came first,
                         the delivery gate rejected it, or parts of it did not land

flags:
  --completion-reserve int
      tokens every call keeps free for its answer and its reasoning (default
      65536); sets AFORGE_COMPLETION_RESERVE for this run
  --context-fill int
      how full a model's context window may get before it is compacted, in
      percent (default 60, clamped 10-90); sets AFORGE_CONTEXT_FILL_PCT for this
      run
  --db string
      work in this durable store instead of a private one
  --debug
      keep the full record of this errand — call bodies, tool calls and the
      choices made — in a folder of its own under the state root (env
      AFORGE_DEBUG)
  --json
      print one machine-readable object instead of the deliverable; settled says
      the errand is over, the exit code says whether it worked, blocked_on
      carries a question nobody was here to answer, and error carries the
      sentence when the run could not start at all
  --keep
      keep the private store instead of deleting it on the way out
  --model string
      work model for this run (flag › AFORGE_MODEL › crew › default)
  --plan-model string
      model that plans, when different from the work model (flag ›
      AFORGE_PLAN_MODEL › crew mastermind › the work model)
  --timeout value
      hard wall, as a duration such as 15m or 2h (a bare number is seconds, kept
      for one release) (default 15m0s)
  -w string
      the directory to work in, edited in place (default: the current directory)
  --yes-spend
      approve a plan whose price crosses the consent threshold

=== aforge exec --help (stdout only)
  aforge exec ["<prompt>"] [-w dir] [--system text] [--turns N] [--budget N] [--timeout seconds]
                         [--model slug] [--plan-model slug] [--context-fill N] [--completion-reserve N]
                         [--json] [-o file] [--debug]
                         run one linear worker with no resident planning graph
                         exit 0 it answered · 2 the token budget ran out · 3 the turn cap came first
                         · 4 the wall came first · 5 it could not be run at all · 6 it stopped with
                         nothing to say. --json carries the same reason in its error field.

flags:
  --budget int
      token budget for the agent (env AFORGE_EXEC_BUDGET) (default 150000)
  --completion-reserve int
      tokens reserved for each answer and its reasoning
  --context-fill int
      context compaction threshold in percent (default 60)
  --debug
      keep the full record of this run — call bodies, tool calls and the
      choices made — in a folder of its own under the state root (env
      AFORGE_DEBUG)
  --json
      print a machine-readable result
  --model string
      work model for this run (flag › AFORGE_MODEL › crew › default)
  -o string
      write the machine-readable result to this file
  --plan-model string
      accepted for headless model-pin parity; exec performs no planning
  --system string
      working method for the agent
  --timeout int
      hard wall in seconds (env AFORGE_EXEC_TIMEOUT; default: scale from the
      token budget)
  --turns int
      runaway backstop on agent iterations (env AFORGE_EXEC_TURNS) (default 200)
  -w string
      workspace directory (default .)

=== aforge run --help (stdout only)
  aforge run  <graph.json> [-w dir] [-j 8] [-o done.json] [--yes-spend] [--model slug] [--plan-model slug]
                         plan and run are the static pipeline: a graph written to a file, then executed
                         exactly as written. Kept for reading, editing, and inspecting a plan by hand.

flags:
  --budget int
      token budget per leaf — the limit that actually binds (default 150000)
  --contracts
      write a per-leaf working method before executing (default true)
  -j int
      how many leaves may run at once (default 32)
  --model string
      work model for this run (flag › AFORGE_MODEL › crew › default)
  -o string
      write the completed graph as JSON to this file
  --plan-model string
      model for briefs, contracts, and recalibration, when different from the
      work model (flag › AFORGE_PLAN_MODEL › crew mastermind › the work
      model)
  --run-budget int
      global token budget for the whole run; once passed, nothing new launches
      and in-flight leaves land (0 = per-leaf budgets only)
  --turns int
      runaway backstop on iterations per leaf (clamped to the executor's own
      backstop) (default 200)
  -w string
      workspace directory (default ./aforge-run-<goal hash>)
  --yes-spend
      preauthorize raising today's dollar rail when reached
