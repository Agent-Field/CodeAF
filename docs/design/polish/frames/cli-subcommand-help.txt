### aforge do --help
Usage of do:
  -completion-reserve int
    	tokens every call keeps free for its answer and its reasoning (default 65536); sets AFORGE_COMPLETION_RESERVE for this run
  -context-fill int
    	how full a model's context window may get before it is compacted, in percent (default 60, clamped 10-90); sets AFORGE_CONTEXT_FILL_PCT for this run
  -db string
    	work in this durable store instead of a private one
  -debug
    	keep the full record of this errand — call bodies, tool calls and the choices made — in a folder of its own under the state root (env AFORGE_DEBUG)
  -json
    	print one machine-readable object instead of the deliverable; settled says the errand is over, the exit code says whether it worked, blocked_on carries a question nobody was here to answer, and error carries the sentence when the run could not start at all
  -keep
    	keep the private store instead of deleting it on the way out
  -model string
    	work model for this run (flag › AFORGE_MODEL › crew › default)
  -plan-model string
    	model that plans, when different from the work model (flag › AFORGE_PLAN_MODEL › crew mastermind › the work model)
  -timeout value
    	hard wall, as a duration such as 15m or 2h (a bare number is seconds, kept for one release) (default 15m0s)
  -w string
    	the directory to work in, edited in place (default: the current directory)
  -yes-spend
    	approve a plan whose price crosses the consent threshold
error: flag: help requested
exit=1

### aforge plan --help
Usage of plan:
  -brief
    	write a self-contained instruction for every leaf
  -ensemble int
    	0 decide from the goal, -1 never, N>=2 force N independent passes and merge them
  -json
    	print the graph as JSON instead of a table
  -model string
    	work model for this run (flag › AFORGE_MODEL › crew › default)
  -o string
    	write the graph as JSON to this file
  -plan-model string
    	model that plans, when different from the work model (flag › AFORGE_PLAN_MODEL › crew mastermind › the work model)
  -w string
    	directory holding the material this goal is about, read once to ground the plan

### aforge exec --help
Usage of exec:
  -budget int
    	token budget for the agent (env AFORGE_EXEC_BUDGET) (default 150000)
  -completion-reserve int
    	tokens reserved for each answer and its reasoning
  -context-fill int
    	context compaction threshold in percent (default 60)
  -debug
    	keep the full record of this run — call bodies, tool calls and the choices made — in a folder of its own under the state root (env AFORGE_DEBUG)
  -json
    	print a machine-readable result
  -model string
    	work model for this run (flag › AFORGE_MODEL › crew › default)
  -o string
    	write the machine-readable result to this file
  -plan-model string
    	accepted for headless model-pin parity; exec performs no planning
  -system string
    	working method for the agent
  -timeout int
    	hard wall in seconds (env AFORGE_EXEC_TIMEOUT; default: scale from the token budget)
  -turns int
    	runaway backstop on agent iterations (env AFORGE_EXEC_TURNS) (default 200)
  -w string
    	workspace directory (default ".")
error: flag: help requested
exit=1
