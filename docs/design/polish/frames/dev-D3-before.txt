  aforge do   "<task>" [--db path] [--keep] [--dir dir] [--timeout 15m]
              [--json] [--yes-spend] [--model slug] [--plan-model slug]
              [--context-fill 60] [--completion-reserve 65536] [--debug]
      do one task and exit — the same living agent the chat runs, with nobody
      watching. What you type is the goal, and it is run verbatim
  the three differ by how much thinking happens first: do plans and may split
  the job, exec does not plan, run follows a plan somebody saved. All three
  end the same way, and why is in --json's stop field:
  exit 0 done · 1 could not be run at all · 2 ran and did not finish
  · 3 a limit you set stopped it · 4 needed an answer and nobody was there
  AFORGE_EXIT_CODES=legacy restores exec's old 2/3/4/5/6 for one release

flags:
  --completion-reserve int
      tokens every call keeps free for its answer and its reasoning (default
      65536)
  --context-fill int
      how full a model's context window may get before it is compacted, in
      percent (default 60, clamped 10-90)
  --db string
      work in this durable store instead of a private one
  --debug
      keep the full record of this run — call bodies, tool calls and the choices
      made — in a folder of its own under the state root (env AFORGE_DEBUG)
  --dir string
      the directory to work in, edited in place (default: the current directory)
  --json
      print one machine-readable object instead of the answer: ok says whether
      the work stands, stop says why it ended, answer carries what was produced,
      files what it wrote, and error the sentence when it could not be run at
      all
  --keep
      keep the private store instead of deleting it on the way out
  --model string
      work model for this run (flag › AFORGE_MODEL › crew › default)
  --plan-model string
      model that plans, when different from the work model (flag ›
      AFORGE_PLAN_MODEL › crew mastermind › the work model)
  --timeout value
      hard wall, as a duration such as 15m or 2h (a bare number is seconds, kept
      for one release) (default 15m0s)
  --yes-spend
      spend past today's limit and past the plan-price question, without
      stopping to ask

run `aforge --help` for every command, `aforge help env` for the variables.
exit=0
