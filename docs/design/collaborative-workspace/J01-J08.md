# J01–J08 harness — Wave 1 actions by frozen names

Proof lane (`t-w1-proof`). This is the committed harness for J01–J08 **actions**,
spelled as `CONTRACTS.md` froze them. Live tmux with a real model is `t-w1-live`,
not a pass of this lane.

Journeys: `USER-JOURNEYS.md`. Person-facing copy: `internal/manual/chat/collections.md`.
Compile-today tests (proof owns these; TUI owns `internal/tui3/*_test.go`):

- `go test ./internal/manual/ -count=1 -timeout 3m` — `chat_test.go` probes and
  `folders_journey_test.go` frozen-name quotes
- Untagged `go test ./internal/e2e/` needles stay in `tuiwords_test.go` when a
  person-facing TUI string lands. Command-table registration of `/folders` is
  a TUI package test, not this lane.

Do not treat this document as a live-chat pass. Live tmux is `t-w1-live`.

## Frozen names (the contract)

| Surface | Spelling |
|---|---|
| Home panel heading | `folders` |
| Empty whisper | `logical groups of chats · /folders create Billing` |
| Slash | `/folders` — **not** an alias of `/folder` |
| Create | `/folders create <name>` |
| File current chat | `/folders add <name-or-id>` |
| Verb strip (`→` on a folders row) | `n` new chat here · `f` add current chat · `m` move this placement · `w` why here · `x` remove this placement |
| Dual placement | `also in` |
| Tool | `folders` (list / file / unfile / move), absent if unwired |
| Root | virtual; never a `collections` CLI row |

Filesystem `/folder` `/place` `/dir` stay filesystem.

## Actions by journey

| ID | Frozen actions | Pass looks like |
|---|---|---|
| J01 | Land on home without choosing a folder. Send. Leave. Reopen. Separately: `n` new chat here, then `esc` before a first message. | First chat is under Root with its own 16-hex id. `esc` creates no transcript. Root is not a filesystem path. | J02 | `/folders create` Billing, Receipts, Security. Place Receipts under Billing and under Security. Rename. Attempt a cycle. | Both paths are the same folder. Rename shows on both. Cycle refused with no partial mutation. Root is not in `codeaf collections list`. |

| J04 | `/folders add` an old chat. `m` move only the Billing placement into Receipts. `x` remove the Security placement. | Unrelated placements stay. Remove does not delete the chat. |
| J05 | `w` why here. Manual add/remove/move. Open filesystem `/folder` before and after. | Actor and reason retained. `/folder` still names the same directory. CLI `codeaf collections` still works. |
| J06 | Type in the composer. Change placements from another window. `x` the selected placement while the chat stays open. | Composer text and selected object survive. No model call on paint. |
| J07 | Browse nested/shared folders at wide and 80 columns. Open a chat and `esc` back. | Sequential drill-in at 80 columns; `esc` back. Shared paths do not double totals. |
| J08 | Quit and reopen with the same `CODEAF_HOME`. List a v1 collection fixture, then first write. Foreign/future/damaged DB. | Graph survives. Listing does not secretly migrate. Unsupported DB is refused, never reset. |
