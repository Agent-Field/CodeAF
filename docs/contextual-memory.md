# Contextual memory (retired)

The contextual-memory layer this page described — evidence and receipts per
claim, binding reads of approved rules and confirmed decisions, observed-outcome
advisories, cross-project impact links, dismissals and the `memory_evidence`
tool — was removed on 2026-10-14 when memory became one strength: every kept line
rides every conversation in its scope, and nothing decides per message what the
model sees.

`docs/memory-architecture.md` describes what memory is now. The full text of this
page, as it stood when the layer shipped, is in git history:

```sh
git log --follow -p -- docs/contextual-memory.md
```
