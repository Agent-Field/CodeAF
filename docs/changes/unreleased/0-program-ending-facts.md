  - "Was true: a program's `end` line in `delegate-actions.jsonl` kept status and one sentence, so a surface wanting what senior-dev claimed beside what it checked, or how many findings a review held, had to read them out of prose. Is true now: the `end` line carries `data`, a bounded allow-listed copy of the terminal's data (`claim`, `observed`, `submitted`, senior-dev's `submission_reason`, `status`, `verification_failing`, `verification_commands`, `reports`, the counts, `partial`, `analysis_incomplete`, `hunt_coverage`), and `delegate.Shown` carries it typed as `ending`. A key of the wrong shape, a JSON null, or a list with a null element is dropped, never coerced, so a count nobody said is absent, not 0. The inner `status` is the program's word on its own work and is not the run's status. The app wire's `TaskPage` carried no program object when this landed; `0-program-wire.md` adds it."
  - "Was true (earlier on this branch): `hunt_coverage` was copied when it merely parsed, so `{\"attempted\":4}` read as none of four failing, sec's real unreadable-accounting ending (`{\"attempted\":0,\"failures\":null,\"unknown\":true}`) was dropped whole, and report paths were cut and whitespace-folded. Is true now: `hunt_coverage` follows sec's own reader (`schemas.Coverage`) — `unknown:true` is `{\"unknown\":true}` alone; otherwise `attempted` >= 1, a non-null `failures` no longer than `attempted`, and every row naming strategy and reason, or the account is `{\"unknown\":true}`, never absent and never a zero. More than 16 failures, a key spelled in another case, or a number with a point or exponent is unknown. A report name that is empty, over 256 bytes, or not already one line drops the whole list rather than being rewritten."
  - "Was true: sec's pass when an audit of the changes found no change ended with data `{\"status\":\"pass\"}` only, so it could be told from a real audit only by the counts being missing. Is true now: that one ending also writes `nothing_to_audit: true`, the `end` line and `Shown.ending` keep it, and it is TRUE-ONLY — a false or any other shape is absent, an audit that ran never writes it, and an older log's line is not read from its sentence."
