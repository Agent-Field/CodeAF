Knowledge updates compare reviewed additions with existing guide sections,
retain incidental reports as linked evidence, and merge overlapping explanations
when needed to keep the guide concise. Support and meaning-coverage checks guard
merged prose; failed updates retain the previous publication. Existing libraries
receive the same cleanup without reimporting saved history.

Validated complete requests remain reusable across updates. Exact local indexing
and bounded fresh batching reduce repeated compiler work, while background calls
retain provider cache affinity. Source admission and human overrides remain intact.
