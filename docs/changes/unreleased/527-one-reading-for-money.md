drew `$1.85 / $500.00` over a spend place drawing `today $0.13 of $500` on the same frame
— fourteen times apart against one denominator — and which of the two you were shown

home SCREEN and `dropHome` empties that on the way out.

today are two readings that disagree later. The usage ledger is the only one that sees
every call — a row is written as each call's bill is decoded, interrupted turns included
(290-one-ledger-one-number) — so it is the one the top line reads, through the one
function the spend place already draws with, reached through a door that takes a
connection's cache before this machine's file so a hosted window shows the far machine's
