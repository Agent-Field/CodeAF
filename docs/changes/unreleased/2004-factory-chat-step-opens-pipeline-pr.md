invalidates:
  - "Was true: a step banked from a chat (`factory_recipe`) was appended after the last step, so it ran after proof, on work nobody proved; and the change was made in a local worktree of the checkout, committed with git and opened with `gh` when it was installed. Is true now: a new step goes in before proof (a step of the same name is still changed where it stands), on the card's before and after line and in the file. When the app holds the factory connection, the yes takes the pipeline editor's road: the file is read from the default branch through the factory, the line becomes the editor's own edit (add_step before proof, set_step, or the rules list), and the pull request is opened through the factory's open-pr route as the signed-in person, from the commit the file was read at. The editor's rules apply as they would to the person's edit, and a step only the editor can add (check, post) is refused with that reason. Without the app the checkout road stays."
