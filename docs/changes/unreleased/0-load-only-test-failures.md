A fork now joins the family of the workspace it was cut from, so claims, the conflict radar and coord values reach its siblings. The watcher ignores file reads, so a seal no longer wakes the next one. Opening a store takes the catalog lock before the pack lock, the order a capture uses. A division's parts seal their ground under the repository lock, so a sibling's half-made worktree cannot fail a seal. A publish after a create whose answer was lost takes the lease it already holds. The terminal suite starts without an ambient API key.
