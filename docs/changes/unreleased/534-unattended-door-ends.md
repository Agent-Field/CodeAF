invalidates:
  - "A handover SEALED a turn without asking anybody anything, so the three roads that move a running turn's work onto a task — a split at a mark, the write seam, the ceiling — were the one ending an unattended session's goal owner never saw. A run whose only turn was handed over inside two minutes had no road back at all: every landing woke a turn that handed over again, and three measured cells finished their work, went green, and still ran to their wall with the top task reading `needs you`. Under a steward those three roads now put the same reading to the same principal a stopped turn does, before they seal, and the answer is journaled as a `steward`/`decided` row exactly as a stopped turn's is. What that reading may do is bounded: A TURN IS NOT ENDED OVER RESULTS ITS MODEL HAS NOT READ. The batch that reaches a handover holds tool results the reply has not answered yet, so nothing left and nothing running still hands the work over exactly as it always did — being finished is decided one reply later, at the next stopped turn, where the last thing that happened was the model speaking. The same thing left twice is a stop with its reason, and that one takes effect where it stands, because no further reply would change it. A session somebody is sitting in front of is unchanged and writes nothing. And the reading and the seal are one step, taken without letting go of the task graph's lock in between, so a task admitted while the goal owner was deciding cannot be sealed over: a stop that meets moving work becomes the carry-on it actually is and is said again at the next ending. The one exception is the budget's own stop — a run that has spent its hours cannot buy the wait — and it says so on the end of its line: `· work was still going and was left where it was`."
  - "An accepted landing that could not be brought home was settled back to `needs your look` whatever had stopped it, so accepting it again ran the same command into the same refusal and raised the same card — a measured run accepted one node three times over a working copy that was not a repository. The two failures are now told apart where the refusal happens, never by matching a message — git says `Permission denied` for a ref it cannot lock in a perfectly writable repository, and a hook may print anything at all, so a refused commit is answered by ASKING THE TREE: a scratch file is written into the repository's own git directory and removed again, and only a refusal carrying the errno of a read-only mount, a permission, a full disk or a spent quota is the place refusing. What is left is the mark: `mergeAborted` is the TREE refusing the work outright (no repository, a read-only mount, a full disk, a folder that cannot take the lay) and settles the node as it stands, done, work left where it is, report leading `taken as it stands, and it could not be brought home, so the work stays where it is — `, with the next resolution on that node answered as already decided; `mergeConflicted` is the same file changed on both sides, which is still a person's to decide and still goes back to needing a look. Nothing merges and nothing is deleted on either road."
  - "One model call could spend a checker's whole five-minute window: a stalled stream ran 183 seconds with no refusal and no error, the window closed, and the node landed saying nobody could check it in five minutes when nobody had in fact been asked twice — and each attempt opened a window of its OWN, so the ladder's two attempts were bounded at ten minutes while the sentence named five. The window is now opened once for the whole of a node's checking and cut into shares, so one call may hold at most half of it: a stalled call is abandoned there (`one call ran 2m30s without answering and was abandoned`) and the check asked again inside what is left, and an answer the retry reaches carries `checked on the second try`. A call is bounded by what is left of the window at the moment it starts rather than by a share fixed in advance, so the overhead between the two attempts cannot leave a retry with almost no time and then blame the checker for it; below a tenth of the window the retry is not made at all and the landing says the window closed. A window too small for a call to be bounded at all makes none, rather than submitting one on a context that has already expired; and a first call that was abandoned keeps its own account when there is no time for a second, which reads `one call ran 2m30s without answering and was abandoned · the window closed before a second`. And a call that stalled is named as a stall wherever it happened, including the one that spent the last of the window itself: `nobody could check it in 5m0s` is kept for the case it is true of — no call stalled, the window simply ran out."
  - "A check that could not run was a question put to somebody even on a run nobody was coming back to: the landing needed a look, woke whoever held the decision, and was settled a round-trip later — which is where the accept loop above then ate the rest of the run. On a run left going with a ceiling (`--yolo` with `--max-hours` or `--max-cost`) the work is now taken as it stands once the check has been asked twice, and the landing says what it did and why, leading with the checker's own account of what became of it: `taken as it stands: one call ran 2m30s without answering and was abandoned · the window closed before a second, and the run is unattended`. It is asked of the CONVERSATION the family hangs off, not of the node's runner — a sub-task is run by its parent node's agent, which holds a person by law — so a headless `--once`, a `--yolo` run with no budget, and a nested task under a session somebody is watching all keep the card they had."
---

Every ending of an unattended run is now read by the same goal owner, and every
landing that cannot come home is settled once. Three cells left running with a
wall each finished their work, went green on the tree, and still ran to the wall:
the turn that moved the work sealed without a decision, the landing that could
not be merged was offered again and again, and the check that would have settled
it spent its window on one hung call. The three are one shape — a run with nobody
in it, asking questions of somebody who is not there — and each of them is now
answered where the answer is knowable.
