---

The choice of which machine serves a model is now the one routing decision a person
can make (#1019 made `simple` the shipped row), so it is worth it being called one
thing. It was called two: the wire, OpenRouter's own refusal text (`provider.only`)
and the owner all said *provider*, while every screen said *lane* — and a person who
went looking for the word they had read had no way to connect it to the word the
error used. Only the words moved; the keys, the file names and the Go identifiers are
where they were.
