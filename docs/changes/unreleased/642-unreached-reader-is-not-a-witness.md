The witness rule is right and it stays: a session's own files are not evidence
about themselves, so work it did with its own hands needs somebody who did not
write them to say nothing is left. What was wrong was the arithmetic of silence.
A reader that could not be reached knows nothing about the work — exactly like a
reader that was never there — and reading either as *the work is unfinished* is
the harness mistaking its own bad afternoon for a fact about the tree.

So the failed call is told apart from the absence, and where it is the only thing
missing the question goes to the one party that IS there: the checks the work
itself named, run over the tree, with the answer said out loud. A lane that is
slow once is slow twice, which is why this is not a retry.
