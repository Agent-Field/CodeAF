A job is a roster row and never a node in the graph, so every room door refuses
its id — the ordinary answer on a perfectly healthy session, which the surface
was reading as "the work has landed". The page a person photographed was 32
seconds into running under a header whose clock was counting up.

The record a job leaves is its log, so the page is now a reading of it, on the
far room's own beat and off the program loop. An empty or unreadable log draws
the line it always drew and never an error over healthy work, and a hosted job
draws no log at all: that path belongs to the other machine.
