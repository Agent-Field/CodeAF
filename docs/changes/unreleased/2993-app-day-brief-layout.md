A day brief built by the app builder used to be a text list of commitments. It now opens with number tiles that say what each count means, a status chart that singles out what is overdue, and rows naming the owner and due date. A review queue's rows show the score alone with a state dot, the record's score says High or Medium, and the agenda and evidence stay on screen in a narrow window.
