Carry the compatible app/v3 pull requests as separate commits, retaining their
individual change entries. Integration keeps dev's shared paid-call identity,
read-first device records, Git maintenance settings scoped to owned copies, and
bounded shutdown ownership.

Overlapping work retains Library billing activity, the shared document and lease
caches, Windows-safe file replacement, and newer Factory approval and recovery
rules. Explicit Test completion choices remain in saved pipeline YAML, and
unchanged-floor settlement passes remain measurable without decoding jobs.

Fixture setup previously relied on idle inventory and synchronous receipt
completion. Fixtures now save their Memory choice explicitly, request the
discovery passes they exercise, and join existing receipt settlement signals.
Admission probes arm their ledger changes after construction, at the turn
boundary they exercise.

Known-free auxiliary calls retain their documented daily-limit exemption through
model selection and the final transport gate. Paid substitutions still check the
shared live daily authority before dispatch.

Sharing fixtures establish their paired profile before recording their first
turn. Encrypted agent custody can create a solo profile during that save;
creating an identity afterward deliberately preserves its existing sync posture.
The fixtures retain the notices, displacement, ownership, and once-only read
assertions, alongside the separate quiet-profile and custody coverage.

Automatic admission invalidates a shared negative job lookup immediately when
the floor changes, so a stopped job handed to a chat is seen on the next ask.
The cheap idle watcher still reads no unchanged job documents.

The Factory PR-base tool-belt fixture keeps its profile outside its workspace,
preserving the existing refusal to work in a folder that contains codeaf state.

The usage writer owns journal synchronization across caller lifetimes. A
recording caller no longer lends its clock scope to a process-wide batch, while
journal batching, crash recovery, and joined shutdown keep their existing bounds.
