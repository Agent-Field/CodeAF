The failure this is written against happened inside one diff: a landing whose
change entry, prose and comments all said the `$0.00` status-line exception had
been taken out, while the function returning `"$0.00"` was still there and still
being called. The work met its acceptance. The manual gates were satisfied —
they check that a name is mentioned, never that the claim around it is true, and
CLAUDE.md says so about itself. So the repository's own opening warning got
reproduced inside a single change, in the direction of the documents.

Nothing here knows what a repository is. "The page no longer says X", "the three
follow-ups were sent", "the table has forty rows" are all claims, and all of them
are checked the same way: read what is asserted, then go and look.
