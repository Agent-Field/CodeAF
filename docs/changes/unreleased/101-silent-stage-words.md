Two full model runs stood between a person and their work with nothing drawn for
either: thirteen measured seconds deciding whether a job is handed out in parts,
often on a card that had only just appeared, and fifteen to thirty seconds writing
the instruction a handed-over turn's worker opens on, before any task exists to
point at. Both read as work that had hung.

The division's reading is a life of the node, so it rides the phase the check and
a repair round already ride. The handover's writing happens before there is a node,
so it rides the turn's own clock — which says only what is true while it is true
and takes itself off the screen either way, because that road can still decide the
work was already finished and leave the turn where it was. Refusals that cost
nothing still draw nothing.
