  - "A question the session was blocked on kept the keyboard after ctrl+t opened the New chat start page over it, so the letters typed into that page's box answered it: `hello there` lost its `t` to \"always, this tool\", which on a shell command opened the widening beat where the next digit in the sentence banked a session rule and ran the command; `esc` denied or cancelled the question behind the page rather than closing the page. Every key on that page is the page's own now — the approval question, the task proposal, the standing card, the connect offer and the harness offer all hand their letters back to it, exactly as they hand them back to home."
  - "The approval block, the connect offer and the harness offer were drawn at the foot of the start page, offering keys it could not honour. They are not drawn there at all now: a question is drawn where it can be answered, which is the conversation behind the page. That chat's tab still wears `?`, Chats still says `asking you something`, the desktop banner still goes out, and `esc` comes back to it with the offer and its letters live. The countdown still pauses at expiry rather than denying, so a question left behind the page is still there when you get to it."
  - "The harness offer swallowed the three chat chords — every other key does nothing while its row is up, its page said, and it meant ctrl+t, ctrl+w and ctrl+k too. It passes them now, on the same terms the permission question and the sign-in offer have always passed them: they move you, they never answer, and the offer is still standing when you come back."

The guard was already written three times, for home, in the words this one borrows:
a question nobody can see is a question nobody can answer. The start page is the
second screen that hides one — and unlike home it has a box of its own, which is
what turned a hidden question into a letter of somebody's first sentence
authorizing a tool for the session. It is not closed by an arriving question the
way home is, because it may be holding a half-written first message; the question
simply stays with the chat it belongs to.
