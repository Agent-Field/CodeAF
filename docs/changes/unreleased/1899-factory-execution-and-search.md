title: Factory conversations keep their model, branches use their person, and file search works without fd
pr: 1899
surface: [engine, chat, docs]
---

Finished stage chats restore their recorded execution model when reopened.
Worker reports preserve that model through a compatibility header, so older
strict factories still receive the results and costs. New
app factory branches use the job person's namespace, while existing branch
records remain valid for recovery and Drop. Queue repositories explicitly carry
false checkout status instead of leaving an uncloned repository unknown.
The find tool has a bounded file-walking fallback and no longer claims a failed
download when fd is absent. It needs no install or network access.


A solo Start now records the authenticated caller even without assignment. Live
step chat identities cross the worker boundary in a compatible header. Final
stage reports end the turn after saving the tool receipt, and provider turn
errors no longer announce false stage failures to the manager. Full journal
command receipts preserve the starting folder, flags, outcomes and explicit
Go test counts for later stages. File glob fallback handles brace alternatives.

Default internal approval steps can be skipped by the person; doing so retains
separate publishing approval. Publishing creates a draft PR with an implementation
summary instead of copying the issue body. The desktop explains what approval
will do, shows current publication and merge blockers, names failed GitHub checks,
and links their detail. Check transitions also reach the Timeline. Factory chats
hide the internal no-change sentinel and active steps show their live command actions.


Open factory PRs now use the existing worker queue for bounded CI repair: triage,
focused tests and proof on the same branch, followed by approval to update the existing
PR. Repairs are deduplicated by head, retain the job cap and pause for unrelated or
uncertain failures. Factory conversations are job-owned, excluded from Agents and
removed on Drop even across earlier rounds. Step frames show full results and omit
the secondary activity line. Proof counts include policy claims, PRs say draft, all
merge blockers are explained, and measured test totals override guessed prose counts.
