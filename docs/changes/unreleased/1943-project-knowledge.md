Memory offers an opt-in project knowledge vault with linked Markdown articles,
folder navigation, search, readable source quotations, and a knowledge model
setting. Saved chat turns support incremental capture and sourced agent recall.

Edit page Markdown or confirm a deletion from the reader. Human edits survive
background compilation and are distinguished from original source history.
Deleted canonical pages stay out of browsing and recall; original chats and
related pages remain. Saved memory stays available for concise standing context.

Knowledge compilation is experimental. Editing and deletion publish locally
without model calls; deleting a page is not semantic erasure from source chats.
