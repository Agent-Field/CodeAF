The whole wave was driven rather than reasoned about. `scripts/frame.sh` runs the
real binary in a real terminal at a named size and writes the frame down, and
every row in `docs/design/polish/LEDGER.md` closes on a captured before/after
pair rather than on an argument — which is how several of these were found at
all, and how one claim in the audit (a wordmark said to be clipped) was caught
being wrong.

`docs/design/polish/COMMANDS.md` is the command vocabulary as a designed system —
the verbs, the nouns, one spelling per flag, what goes to stdout and what to
stderr, what each exit code means, what `--json` guarantees, and the mapping
between a CLI verb and its slash command. `docs/design/polish/envelope-and-exits.md`
carries the before and after for anyone with a script in production.
