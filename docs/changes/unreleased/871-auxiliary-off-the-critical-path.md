THE LAW, stated in loop.go's header and guarded by two tests: **the only wait a
person experiences is the main model generating**. Every reading this harness
makes on its own behalf — which remembered lines a message needs, what is left of
a long answer, whether a message was really work, a name, a caption — runs BESIDE
the work and may only INTERRUPT it. A person's message reaches the wire within
50 ms, and so does a tool result.

Quality is kept by APPLYING every decision rather than by awaiting it: in time,
and it is spent on this step; late, and it is spent on the next one or written
down as late. Nothing is dropped, because a dropped reading is a reading whose
ledger never learns.
