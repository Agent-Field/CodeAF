---
kind: fixed
title: Nine defects the hand QA of dev found in the chat are fixed
pr: 2707
surface: [chat, engine, docs]
invalidates:
  - "A critical-command approval card (for example `rm -rf` of a real path) opened with the pointer on `1 allow once`, or on `2 always, this command`, so an unaimed enter ran it. It now opens on `3 deny`, whether the model asked or the command was typed after `!`, and a grave call no longer offers the always answer."
  - "Dropping a banked `always, this tool` rule in `/permissions` left the running conversation using it for the rest of the session. The next tool decision, in that conversation and in any other on the same engine, now asks again."
  - "In a conversation, `@file:` and `/export` completion said `no file matches` once a word-argument completion such as `/atlas ` had been opened. They now list the workspace's files."
  - "`/export` after `/compact` wrote only the turns that survived compaction, and the manual described a stamped file name the code never produced. It now writes the whole conversation, and the manual gives the real default name, `transcript-<session name>.md`."
  - "The `/crew` seat picker offered none of the `claude-code/*` models that `/model` lists. It now lists the same family and version rows, marked `on your Claude plan`."
  - "`codeaf chat --no-host` and `CODEAF_DEBUG=1 codeaf` opened a folder under `/tmp` without its project, so `/remember` said `for you everywhere` and the keys row ended `project: codeaf`. Both now anchor to the working folder exactly as the plain launch does."
  - "`codeaf do --json` printed `calls: 0` for a run that made several model calls. It now counts the calls the run made, as v0.8.2 did."
  - "`/spend` by topic left out the background knowledge compiler's money, so its rows added up to less than the page's own total. By topic now has a `learning from your conversations` row, and any other row without an id lands under `other work`."
  - "`/cost` took its tokens and calls from an end-of-turn snapshot while its dollars came from the ledger, and `/model` repriced the cache savings already earned. The counts now follow the ledger, and each model's cached reads stay priced at that model's own rate."
  - "The Memory tab's detail pane wrote `now ago` for a line kept a moment ago, and bare `/always` printed `· ·` at the head of its first line. The pane now says `now` or `3m ago`, and the listing prints one bullet per line."
---
Each fix has a regression test written from the issue's own acceptance, and each was run by hand against the built binary: the scripted endpoint for the approval, permissions, completion, crew and memory flows, and a cheap real model for export, spend, cost and `codeaf do`.
