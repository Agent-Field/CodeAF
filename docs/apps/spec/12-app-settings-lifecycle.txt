1 App ⌄ sits at the right end of every app’s header line (CodeAF-owned, same in every app). Click, or right-click the app’s rail row, or the menu bar App menu. Esc closes. The same items show for every role; an item you may not use is dimmed with the reason on its right.
2 Versions… · Open files · Make my copy. Versions lists every applied change with the request text, who and Restore (card Versions). Open files opens the app’s files in a new tab, read-only: app.json , plan.json , screens/ , runs/ , agent.md ; changes go through Shape so they get Check and a version.
3 Needs · Triggers · Budget · Members each open a sheet that hangs from the top of the card (cards below). The number on the right is live: capabilities, triggers on and paused, spent this month, people with a role.
4 Lifecycle. Move to workspace… only on a personal app (here dimmed: CRM already lives in acme). Archive app… hides the app and keeps every record. Delete app… only for the workspace Owner and Admins; it asks for the app’s name and keeps records 30 days.
5 Everyone in acme sees the same CRM. Header meta reads home · version · who shaped it last. App ⌄ items that change the app for everyone (Restore, triggers, members, archive) write one Activity line each, with Undo where it can be undone.

Start from ⌘K “CRM: Import records…”, the menu bar File → Import into CRM…, or an empty record list. Import is a sheet over the app; it writes real records directly (no draft).

An import never changes the app: a column with no field is kept as a note or skipped; to add a field, Shape the app first.
