Who An Editor or User of the app, or the app’s agent. One holder per part.
Taken by Starting a nudge, or an Ask on that part. Viewing and commenting never take it.
Released On Done ↵ or Esc, when the agent finishes, or after 2 minutes idle .
Agent lock Ask to take over reads "Stop the agent". The agent stops; its unfinished edit is not written.
Offline A holder who goes offline loses the lock at once; unsaved words stay in their draft.

section-2.md artboards/cart.json A Docs page splits into sections (Markdown, Text surface); a Design app into artboards (positioned boxes, Canvas surface, like slides). Same parts strip, same Ask · Nudge · Comment, same lock, presence and versions per part, same Present · Share · Export.
1 Parts make it collaborative. A document is a list of parts; here each slide is one part = one file ( slides/3.json , positioned boxes: text, image, shape, chart) + one record (status Draft · In review · Final, owner, comments). The Canvas surface renders it; the deck is a record of the Slides app. Drag a thumbnail to reorder; ⌥-drag duplicates.
2 Ask · Nudge · Comment are the only three ways to change a part. Ask hands the selected part to the app's agent, the Slides agent (pane on the right, ⌘L); it changes content only, never the app. Nudge (N, or double-click text) edits words in place or drags a box. Comment (C, then click an element) pins a note on that element.
3 One writer per part. The writer holds a light lock: the thumbnail dims with a slow shimmer and reads "agent is editing" or "Mona is editing". Everyone else keeps working on the other parts. Presence avatars show who is looking at which part; looking never locks.
4 Versions per part. Every Ask, Nudge or Restore writes a new version of that one file (slide 3 is at v5). Versions shows before/after thumbnails with Restore. The deck itself has no version number.
5 Out: Present (full screen, ⌘↵), Share (a link for members of acme, served by acme’s codeaf server) and Export ⌄ PDF · PPTX. Export renders every part as it is now.
6 No live co-typing, on purpose. Two people never type in the same part at once. A nudge holds the lock only until Done ↵ (or 2 minutes idle); then the next person can take it. Comments never lock.
