1 Prompt. New app… (rail or ⌘K) opens the same sheet as every app (L1). Home acme: members of the acme workspace see it after the first Apply. Connectors list only accounts in Settings → Accounts; here GitHub. Create app ↵ opens the tab "Bugfix factory · building".
2 Plan first. The Builder (CodeAF's own agent, the same for every app) answers with plan.json; CodeAF draws this card from it, always the same: Data (records, documents, reads), Automation (triggers, runs), Screens, Agent. Needs is computed by CodeAF from those sections, so the Builder cannot understate what the app will use. Write it (↵) starts writing. Change plan docks the Builder pane with the plan quoted; the Builder answers with a new plan card. The Agent line describes the app's own agent, which later works on jobs only. Gates read exactly as they will run: approval: plan, approval: proof.
3 Files. app.json, runs/fix.yaml, screens/jobs.json, screens/job.json, agent.md. Only runs touch shells: code and test declare workspace: repo , so they get a checkout, a branch and a shell on the assignee's runner. Screens are declarative JSON: a tree of kit parts with bindings to records and runs; no imports, no code. custom/*.tsx (sandboxed, labelled custom) is the escape hatch only. App ⌄ → Open files shows them.
4 Checks. Schema check, Kit law, Render with sample data, Behaviour check (runs on sample data against connector fakes), in that order. A failing check goes back to the Builder with file and line (max 3 rounds); after round 3 it shows you the error with Fix it · Cancel. Passed rounds fold to one line; click to unfold.
5 Preview. The new rail row "Bugfix factory" sits with the workspace apps and reads preview. QueryField, StateMeter (Needs you · Running · Queued · Backlog · Done), RecordList rows and the right Panel are the kit's, so the screen matches acme's Jobs. Keep writes v1, private to you until the first Apply; Shape more opens the Builder pane; Discard removes the app and its row.
6 Job page. RunTimeline shows the loop as a parent row with rounds under its steps; LogStream follows the step you select; ProofList and DiffViewer feed the ApprovalCard. Approve sends the run on to open PR via GitHub, as you, with a 5-second Undo. The approval also waits in Inbox.
7 Ours vs generated. The generated factory has Jobs and Job only. It has no Repos or Runners pages: runners come from CodeAF (Settings → Factory). A Repos page is one Shape away; it runs as a draft only you see until Apply.
