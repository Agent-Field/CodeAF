Polls the plandb queue for the current review run and returns once all
auto-enqueued review tasks (Investigators, Provers) have drained — or
when the timeout elapses.

Used by the Synthesizer agent at startup. Provers are dispatched
event-driven by the `review_candidate(op="add")` tool, so the
Synthesizer cannot assume the proofs are complete just because the
upstream Investigators returned. Call this once before reading
`.review/lens/*/proofs/F*.md`.

Parameters:

- `max_seconds` (optional, default 600): max wall time to wait. The
  tool returns as soon as plandb pending count hits 0, otherwise it
  returns after this many seconds with `timed_out: true`.
- `poll_seconds` (optional, default 5): seconds between polls.

Return: a markdown line summarising the wait — e.g.
"plandb drained in 47s; 12 prover tasks completed" or
"timed out after 600s; 3 prover tasks still running".

Safe to call multiple times — it's idempotent.
