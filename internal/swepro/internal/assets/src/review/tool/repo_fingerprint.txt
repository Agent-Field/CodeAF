Detects the shape of the repository: languages, frameworks, build system,
test runner, infra hints, and CI presence. Returns markdown.

No LLM, no LSP — pure file/heuristic detection. Output is the same for
the same repo state. Cheap; call once at the start of a review run.

Parameters: none (operates on the project working directory).

Output sections:

- **Languages** — extensions counted across non-vendored files (top 6)
- **Lockfiles / package managers** — package-lock.json, yarn.lock, bun.lock, pnpm-lock.yaml, go.sum, Cargo.lock, poetry.lock, Pipfile.lock, requirements.txt
- **Frameworks** — sniffed from manifest contents (React, Next.js, Vue, Express, FastAPI, Django, Flask, Rails, gRPC, etc.)
- **Build system** — bun, npm, go, cargo, make, pip, poetry, gradle, maven, etc.
- **Test runner** — jest, vitest, mocha, pytest, go test, cargo test, etc.
- **Infra** — Dockerfile, docker-compose.yml, k8s manifests, Terraform, Helm charts
- **CI** — .github/workflows, .gitlab-ci.yml, .circleci/, Jenkinsfile

This is a fingerprint, not a manifest — it tells you the shape, not the
inventory. Always cross-check by reading the specific files referenced.
