# Desktop All places root Home

## What is All places in the desktop app?

All places opens the root Home in a tab. The window uses graphite. The title is
“All places”; below it, the count names the top-level places and every active
place, for example “5 at the top level · 58 in all”. Unknown counts draw nothing.
Top-level places appear as tiles. Open a tile to go to that place.

## How do I search places by name or ancestor path?

Use “Search places” on All places. Matching ignores case and surrounding spaces
and searches both the place’s name and its ancestor path. Nested results show
where they belong. The same field filters unplaced chats by their titles.
Escape clears the search and restores the top-level tiles and unplaced list.
Search uses the data already loaded from the engine; it makes no model call.

## Where are chats not in any place?

On All places, “Not in any place · N” lists unplaced chats. N is the engine’s
total, even if the current read or search shows fewer rows. Click a chat to open
it. An empty list draws nothing. A chat filed in a place does not appear here.
