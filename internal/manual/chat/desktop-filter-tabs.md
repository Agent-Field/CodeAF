# Filter tabs

## How filter tabs work in the desktop app

Filter tabs are a row of pills that choose one filter. The chosen pill is filled. The others stay quiet. Click a pill to choose it. A pill that is unavailable is dimmed and does not choose. If the current choice is not one of the pills, none of them is filled.

## Move between filter tabs with the arrow keys

Filter tabs are one tab stop. Arrow keys move to the next pill and choose it. Home jumps to the first pill and End jumps to the last. A pill that is unavailable is skipped. A click chooses a pill and does not draw the keyboard ring. The ring appears when you reach a pill from the keyboard.

## Filter tabs on a narrow window

At a window 600px wide or narrower, filter tabs scroll sideways. An edge fades only while more pills sit past it. A wider window leaves the row still.
