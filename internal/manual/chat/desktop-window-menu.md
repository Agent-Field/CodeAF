# Desktop window menu

## How do I open a new desktop window on macOS?

Choose File → New Window or press ⌘N. The new window opens on Now. macOS handles
this command in the native app menu, including when a web page has keyboard focus.
New Window appears above New Tab. Opening a window does not start another engine.

## How do I switch or close desktop windows?

The macOS Window menu keeps the platform window list. Choose a window there to
bring it forward. File → Close Window closes the window and has no keyboard
shortcut; ⌘⇧W belongs to Close place.

The tab shortcuts remain ⌘T for New Tab, ⌘W for Close Tab, ⌥⌘W for Close and Stop,
⌘⇧T for Reopen Closed Tab, and ⌘⇧] / ⌘⇧[ for Select Next Tab / Select Previous Tab.
Linux and Windows do not have this native app menu.
