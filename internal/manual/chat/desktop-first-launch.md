# Desktop first launch

## How do I make my first desktop place from a folder or repo?

With no places, All places says: "Places hold work that belongs together, with what the AI should know about it. Open a folder or repo to make one, or just name one."

Choose "Open a folder or repo" in the desktop app. The native folder chooser opens. The engine makes a place named after the chosen folder or repository, with that folder as its source, and opens its Home. A folder inside a Git repository uses the repository root. Canceling the chooser creates nothing and leaves you where you were. A refused creation does not navigate. The folder tile is absent in a browser, where there is no native chooser.

## How do I name my first desktop place without a folder?

Choose "Name a place". The tile becomes an inline name field with a tint picker. Enter creates the place; Escape cancels. Blank names cannot submit. A failed save keeps your draft. After the first place exists, the explainer and folder tile leave All places, and the ordinary New place tile stays.

## How do I move Now's matching tabs into my first desktop place?

On the first place's Home, "Move matching tabs" offers one click to move eligible tabs from Now. Matching comes from the engine's saved conversation workspace or membership in that place. Unknown conversations, pinned tabs and navigation tabs stay in Now; a split moves only when every pane matches. Moving keeps tab contents, drafts, groups and saved view state and does not stop running work. Undo returns the moved tabs to Now. With no eligible tabs the offer draws nothing.
