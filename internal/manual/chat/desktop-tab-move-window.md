# Moving a tab to a new window

## How do I move a tab to a new window, and what happens when I drag a tab outside the strip

In the desktop app, the tab menu item Move to new window opens another window on the same place, focused on that tab. Dragging a tab outside the strip does the same thing, and the new window's top-left corner is where you dropped the tab. The menu does not pick a spot, so that window opens 24 pixels down and to the right of the one you used.

The place's tabs are shared, so the tab stays in the first window too. Nothing is closed, copied or stopped, and work that was running keeps running. A web tab is focused the same way: the page is shown in the window that has that tab focused, and the window you left does not keep a second copy of the page.

Only the new window is told which tab to show, and only after that window has finished loading. Another window on the same place does not change the tab it was already showing. If the tab, the place or the drop point is not one codeaf can open, no window appears. A browser has no second window, so Move to new window is not in the menu there.
