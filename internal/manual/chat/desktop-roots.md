# Opening a file on this machine

## Why can't I open a file outside the project

Open in editor and Reveal stay inside the directories the engine reports for this machine. That list is each open conversation's workspace, the directory that holds that conversation, every directory you named for that conversation, and every directory or git repository a place lists, including a place you have archived. A single file listed as a source, a link, and a directory the work merely remembered are not extra roots, so a file outside the project is not opened. Two names for one directory count once. The desktop does not accept a workspace path from the window in place of this list.

## A conversation on another machine reports no folders

When the engine for a conversation is on another machine, that conversation adds no directories. If every open conversation is on another machine, the list is empty, even when a place on this computer lists directories. Nothing here is opened as though it belonged to that engine.
