# Desktop History row actions

## Desktop History row menu: right-click, Shift F10, background tabs, Unarchive and Delete

Right-click a History row to open its actions. With the conversation list focused,
use the arrow keys to select a row, then Shift+F10 or the ContextMenu key to open
that row's menu. Escape closes the menu and returns focus to the list.

Continue opens the live conversation. Read shows saved messages read-only inside
History. A separator precedes Archive, or Unarchive when the row is archived.
Archive is disabled while work is running or waiting for you. Unarchive removes
the archived mark without opening a conversation tab.

Command-click on macOS, Control-click on Linux, or middle-click a row opens the
conversation in a background tab. History stays selected. If the conversation
already has a tab, this gesture leaves History selected and creates no duplicate.

Conversation deletion is not available in the desktop engine yet, so Delete… is
absent from the live History row menu. The row supports a confirmation handler
for a future engine-backed deletion action, only for archived conversations.
Add to place is also absent until its History filing action is connected.
