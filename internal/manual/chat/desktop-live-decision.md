# When a place decides in the chat

## Will a place allow go test without showing me the question

A chat filed in a place is the chat that place can decide for. When that place is already deciding, and it has allowed the same command often enough to clear its threshold, it answers a go test permission before the question is shown. You do not get a card. The receipt names the place and the reason, in the form "Allowed automatically by Release · You allowed go test here 6 times. Costly. · Why?". A chat that is not filed in any place is still asked, even when some place is sure. A place that is still learning does not answer alone: the question is shown, with that place's choice already selected.

## Does answering a question teach the place

Yes, when you answer it. The place records whether you took the choice it had selected, and it keeps what you allowed or denied so the next time it can measure that command. An answer the place took by itself is not you agreeing, so it does not move that count. One agreement does not make the place start deciding. It is still learning until the count reaches 18 of 20. A place that knows a line naming the command can suggest allowing it before it has a history, and the reason says it matches what that place knows.

## Why is a decided question not in needs you

Needs you drops a question once the answer is recorded. That record is the conversation's own answer, or the place's decision ledger for a chat filed there. A place being confident is not enough. Until one of those records exists, the question stays, including when the chat is not filed in the place that would have decided it.
