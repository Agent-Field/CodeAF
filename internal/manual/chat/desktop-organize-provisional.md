# A provisional organizing plan

## Why does it say this plan is provisional

Organize now still offers a plan when the usual model cannot read the chats. The summary then says exactly: "This plan is provisional: a local model embedded the chats."

## What does a provisional plan mean

You can still review that plan, accept it, or leave it. The sentence is how you know a local model read the chats. Nothing else about the plan changes colour or wording.
