# Desktop work and chip feedback

## Why does a completed step stay dim when I hover it?

Completed and stopped step titles keep their quiet text ink when hovered or
clicked. Only the last running step in an expanded work block shimmers. Settling
removes the shimmer and freezes the clock at the recorded duration.

## How do file chips, link chips and the model picker react to clicks?

Hover changes the fill without changing text ink. Pressing a file chip, link chip
or model picker darkens its fill beyond hover. Keyboard focus shows the shared
accent ring and halo. Pointer clicks do not show that ring.
