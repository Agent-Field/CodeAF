# Desktop place plans

## Can I undo a whole place plan in one step

The desktop engine can save an accepted place plan as one change. One Undo
restores the places and chat filings from before that plan, including shortcuts.
Chat transcripts are never deleted. A later change from another window can
prevent Undo; it refuses rather than taking back somebody else's changes.
Undo of a whole plan also restores its prior visit and open-place records.
Any later saved change, including a visit, prevents this exact plan Undo.

This store capability does not add an Organize now button. The organising
controls and draft suggestions need their own desktop and bridge implementation.

## What happens if a place plan contains an invalid change

The engine checks the entire selected plan before saving anything. A missing
place, invalid name, cycle or limit breach leaves your organisation unchanged.
You can leave changes out of a plan; leaving out a place that another selected
change needs refuses the plan. Nothing is partially saved.

## What are the organizing calls per run and cost per run

The organising policy defaults to adding to what is there, 150 calls per run
and five US cents ($0.05) per run. The cost setting uses whole cents. Live draft
place guesses are enabled in the policy by default. These are saved policy
choices; this store change alone does not make the organising or guess controls
available in the desktop.
