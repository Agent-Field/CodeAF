# Desktop queued paste

## How do I edit a queued message that has a pasted text card?

A long paste waiting in the desktop queue shows as the words you typed beside it.
When the message was only the paste, the row reads "Pasted text · N lines".
Click that text to edit it. The field is plain text: the whole stored message,
including the `<pasted-text lines="N">` block and its line breaks. It does not
open as a card. Enter or Save keeps the change. Escape leaves the queued
message as it was.

## Does editing a queued paste show the pasted-text tags?

Yes. The editor is the stored message as plain text, tags included. A queued
row never draws those tags; it draws the typed words, or "Pasted text · N lines"
when there are no typed words. Saving writes the field's text back to the
engine queue. Enter saves. Escape discards the edit.
