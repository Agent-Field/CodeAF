# Organize places from the desktop

## A second Organize now while places are already being organized

If places are already being organized, another Organize now does not start another run. codeaf keeps the run that is going. Cancel ends that run, and a cancelled run changes nothing.

## Guessing a place while I type a new chat

While you type a new chat, codeaf can name the place that chat belongs in. A chat you started in a place's folder is named as that place. If guessing is turned off, or you have not typed anything and there is no folder, nothing is named. The guess does not file the chat.

## Also in names a shortcut, not a second home

A chat has one home. Also in is a shortcut to another place, not a second home. The place list counts the chats whose home is that place.

## Views of one place, such as by month

A view is a way of looking at one place, such as by month or by project. Asking to organize a place by month adds the view by month right away. A sentence codeaf cannot read changes nothing.

## Organizing a place says I did not understand that

That sentence means the instruction was not one codeaf can follow. Try by month or by project. Nothing in your places changes.
