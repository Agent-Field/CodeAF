# Desktop search field

## How do I clear and leave the desktop search field with Escape?

The shared desktop search field clears its query and leaves the field when you
press Escape. Escape in an empty field also leaves it. Search words remain literal
text; the page that owns the field decides which real records match them.

## Why does the desktop search shortcut hint disappear?

An empty search field shows its page's shortcut hint, usually ⌘F on a Mac or Ctrl+F
elsewhere. The hint disappears when the field contains text or the window is
600 pixels wide or narrower. The owning page registers the shortcut; the shared
field itself does not claim a global shortcut. Pages adopt this shared control
individually, so it does not change every existing search box at once.

## Why does the desktop search field have a ring only with keyboard focus?

Tab focus draws an accent ring and halo around the search field. Clicking into it
and typing does not draw a ring. The field has a search icon and an accessible
name supplied by its page.
