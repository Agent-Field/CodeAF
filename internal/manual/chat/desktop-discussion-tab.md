# Discussion tab

## How do I open a council discussion from Live or History?

A council opens like any chat, as an ordinary conversation tab. Click its row under Live while it is running, or find it under Recent or in History once it has ended. The tab is titled with both places, for example “Marketing with Software”, and the top of the pane shows each place's tint square beside that title. Only the discussions the engine has recorded open this way; an ordinary chat never turns into one.

## Who said each line in a council tab?

Every line a place says is labelled with that place's name and tint square. A line you typed is drawn as your own message. A line written before the engine recorded who spoke has no label, because codeaf does not guess. A running discussion adds new lines about every second and a half; an ended one is read once.

## Does typing in a council pause it?

Yes. The first character you type in “Add to this discussion” pauses the council before its next turn; a turn already being answered finishes first. Sending your message adds it to the discussion and lets it go on. Clearing the box without sending also lets it go on. When the discussion has ended the box is disabled and reads “This discussion has ended”: an ended council cannot be steered, and no new discussion of the same pair and topic opens for an hour.
