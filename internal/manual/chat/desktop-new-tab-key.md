# Desktop New tab key

## What does ⌘K or Ctrl+K do in the desktop app? Where did the command palette go?

**⌘K** on a Mac, **Ctrl+K** on Windows and Linux, goes to the New tab field: the one line that says "Search or start", where you type words to start a conversation, search history, open a file or a web address, or reopen a closed tab. The focus lands in that field, ready to type.

The four-page command palette is gone. There is no dialog for ⌘K to open, no "Search commands" box and no "Go to Activity" list. A New tab is a field, not a page.

## Does ⌘K open a new empty tab every time?

No. If an empty New tab is already open, ⌘K shows that one and puts the cursor in its field, even when you are on another tab or on another page. It only opens a fresh tab when none is empty. A New tab with words already typed in it counts as in use, so ⌘K leaves it alone and opens another.

## Which keys are different from ⌘K?

**⌘T** or **Ctrl+T** always opens a new tab. **⌘P** or **Ctrl+P** is Go to, the place chooser. **⌘⇧K** or **Ctrl+Shift+K** toggles the Tasks panel. **⌘,** or **Ctrl+,** opens Settings.
