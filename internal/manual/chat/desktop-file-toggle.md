# Desktop file view toggle

## How do I switch Changes and File with the keyboard in a desktop file tab?

In a desktop file or diff tab, Tab reaches the selected Changes/File choice.
Right or Down selects the next choice; Left or Up selects the previous choice.
The arrows wrap between the two choices. Changes shows the diff; File shows
this file's contents. The selected choice is the group's single Tab stop.

A file outside git has only its contents: there is no Changes/File toggle
or changed-line count.

## Why does the desktop file toggle show a focus ring only with the keyboard?

Keyboard focus draws an accent ring and soft halo around the Changes/File
choice. Selecting a choice with the pointer keeps its quiet selected fill
and paper shadow without a focus ring. The ring remains visible when arrow
keys change the selected choice, in both Light and Dark appearance.
