# Desktop Next up end card

## What does You're clear mean at the end of Next up?

The desktop Next up end card says "You're clear" when the walk finishes. It
shows the number answered during that walk and the number of tasks
running across all conversations, including conversations without an open tab.
Unknown or zero counts are omitted. One task reads "1 task is running."

## How do I return from the Next up end card?

Press Esc or click "Back to" followed by the place you started from, for example
"Back to Config stack". Both use the same return action. Returning does not stop
running tasks.
