# Desktop terminal tabs in a narrow window

## Where did the terminal folder and job label go in a narrow window?

At window widths of 600 pixels or less, the terminal header hides its folder and kind label, such as “~/codeaf · job”. The title stays in the header, fading when space runs out. State words stay visible. A running terminal or job keeps its Stop, Copy output and More buttons; finished jobs keep Copy output and More.

## Can I ask about terminal output in a small window?

“Ask codeaf about this output” fills the available pane width inside its usual padding. You can type a question and use Ask or Enter. Resizing the window refits the terminal columns and rows through the existing resize path, including at 320 pixels wide.
