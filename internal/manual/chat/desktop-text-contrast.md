# Desktop text and keyboard scrolling

## Why are desktop link titles and warning messages different colours?

Desktop link chips show their title in full ink, with the domain in muted ink.
A link chip inside an assistant reply keeps those colours. Ordinary prose links
use the accent colour. Warning toasts keep their message in full ink; only their
small status dot uses amber. Light and Dark appearance use the same roles.

## How do I scroll a desktop decision question with the keyboard?

Tab can focus the decision card's scrolling body and its comparison table.
Use the arrow keys to scroll the focused area. The shared keyboard focus ring
shows which area has focus. The decision buttons remain reachable with Tab.
