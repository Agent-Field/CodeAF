# Conversation header Using chip and membership line

## Where does the Using chip sit beside the running counts?

In a conversation, the Using chip sits in the header beside the conversation's name and to the left of the running and needs-you counts. It is the same chip that opens the list of places and sources. A task page's header is the trail back to the conversation, and that trail has no Using chip.

## Does a place change show twice in the transcript?

No. Filing a conversation under a place, or taking it out, draws one line in the transcript, such as "Now also using Release: brand-voice.md", with Undo on that change. The line shows as soon as the place changes. When the conversation's own record of that same change arrives, the recorded line is the one that stays and the earlier copy is not drawn again. A chat with no messages yet still shows the line. A task page does not.
