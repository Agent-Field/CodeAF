# Place instructions on Home

## How do I write instructions for a place?

On a place's Home, instructions are plain prose. The card sits under Chats. It stays off the page when there is nothing written. On an empty place, Write instructions opens it and puts the cursor in the text area. Click the prose to change it. Clicking away saves. The same words are not written again. Clearing the prose and clicking away removes the card. While the engine is offline the prose stays and cannot be edited.

## How do I add a note or drop a file or link?

Under the prose, the field says "Add a note, or drop a file or link…". A note is saved when you leave the field or press Enter, and it becomes another paragraph of the instructions. A blank note is ignored. Dropping a file or an http(s) link adds it as a source of the place. Dropping a chat or another place does nothing here. Typing a link into the note field keeps it as prose.

## What happens if I press Escape while editing instructions?

Escape puts the last saved prose back and writes nothing. On a card that was empty, Escape closes it. Escape in the note field clears what you typed there and does not add it. If a save is refused, the words you typed stay and the reason is shown in ordinary text.
