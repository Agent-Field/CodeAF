# Closing a chat and reading its final save

## A final save says another computer continued this chat or kept turns separately

If the final save finds that the chat has moved to a different machine, the window that closed it still receives `<device> continued this chat; this window now only shows it`. Any sentence about turns kept as a separate copy arrives with it.

Closing one chat while another stays open puts these sentences in the window's notes. Quitting codeaf prints them once after the screen closes, alongside the saving receipt. This also works with `--no-host`. A clean final save adds no sentence.
