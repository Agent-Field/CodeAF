# Desktop place status dots

## What does the amber or red dot beside a desktop place mean?

The desktop rail shows a six-pixel amber dot when something in a place needs you,
or a red dot when a task failed. If both happen, needs-you takes priority.
The dot can include attention from child places. Colour appears only on the mark;
the place name keeps its ordinary text colour.

Hover the dot for words such as "2 need you in Config parser" or
"1 failed task in Config parser". Screen readers receive those same words.
Clicking the dot opens the place, just like clicking its row.

## Why is there no dot when a desktop place is only running?

Running work alone shows no status dot in the desktop rail. Zero or unknown
attention shows nothing. Running work is visible on the place's Home and in
the conversation.
