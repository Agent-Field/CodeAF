# Place flows on the desktop

## Add the first folder on a populated place home

A place that already has chats and no sources still shows Add files or links. The Sources heading and the source list stay hidden until a source exists. Choosing the control opens Files and links for that place. A path that is not on this machine is refused with "That path doesn't exist." and nothing is added. A folder that is there is added, and the Sources list then names it. The same control stays so another file or link can be added. An empty place, with no chats of its own, keeps Add files or links on its empty screen instead.

## Open a folder or repo and land on its home

On All places, when you have no places yet, choose Open a folder or repo. The desktop folder chooser opens. codeaf makes a place named after that folder, with the folder as its one source, and opens that place's Home. The Home tab shows the folder's name, and the composer says "Start something in" that name, because the folder is already a source. Opening the same folder again returns to the place already made. Canceling the chooser creates nothing.

## Undo a saved-to remember line

When a chat saves a knowledge line, the transcript shows "Saved to" the place, then the line, then Undo. That note is the remember control even when the save was recorded beside other place changes. Undo removes that one line. While the removal is in flight the button stays disabled and the words stay. If the line has changed, the chat says "That line has changed." and Undo can be tried again. When the line is removed, the note says Removed and the button is gone.

## Open tabs that share a topic

When three or more open chats sit outside a group, codeaf asks whether they share a topic. The question uses each chat's saved folder, not the temporary session token. If they belong together, a suggestion names that topic. Accepting it puts those tabs together and the suggestion goes away. Dismiss hides that suggestion.
