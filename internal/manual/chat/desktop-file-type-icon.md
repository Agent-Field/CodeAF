# Desktop file type icons

## What icon does a json file show

A file tab draws an icon for the kind of file, on the tab and again in the header. A JSON file (.json, .jsonc or .json5) shows the JSON file icon. A code file, such as .go, .ts or .py, shows the code file icon. Markdown, a .txt file and other writing show the text file icon. A file with no matching icon shows the plain file icon.

## What icon does a picture file tab use

A picture file shows the image icon on its file tab and in the header. That covers .png, .jpg, .jpeg, .gif, .webp, .svg and .avif.

## Does a diff tab use the file icon

A diff tab keeps the diff icon on the tab. The header still shows the file's own icon, so a diff of a Go file shows the code file icon beside the name, and a diff of a JSON file shows the JSON file icon there.
