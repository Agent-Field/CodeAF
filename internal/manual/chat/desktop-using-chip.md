# Using chip in the conversation header

## What is the Using chip in the conversation header?

The chip beside the conversation title reads "Using 3 places · 4 sources", with a layers mark and a chevron. It says which places and sources the conversation is drawing on. Press it, or focus it and press Enter, to open the list; Escape closes it and returns focus to the chip. While open the chip is a shade darker and the chevron points up.

## Why does the header chip show only a place name?

When a conversation uses exactly one place and no sources, the chip is that place's colour square and its name, with no chevron. It still opens the list. With any source, or more than one place, the count shows instead.

## Why is there no Using chip on my conversation?

A conversation in no place and with no sources has nothing to list, so the chip is not drawn. While the list is loading it is also absent. It is read again when a place changes.
