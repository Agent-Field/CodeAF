# Desktop rail place menu

## right-click a place in the rail, rail row menu, context menu
Right-click a place row in the rail, or focus it and press Shift+F10 or the context-menu key. The menu lists Go to, Quick Look, Pin (Unpin when the place is already pinned), Rename, a row of five tint squares, Close and Close all others. A row whose action is not available is left off the menu rather than shown and failing.

## pin or unpin a place from the rail
The menu's Pin row becomes Unpin for a pinned place. Close takes the place off the Open list; work still running keeps its row. Close all others keeps only the place you opened the menu on.
