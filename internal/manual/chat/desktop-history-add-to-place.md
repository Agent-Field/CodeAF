# Desktop History: Add to place

## Add a past conversation to a place from History

Right-click a conversation in History and choose "Add to place". The submenu lists up to ten places, pinned places first and then the ones opened most recently. Choosing one files the conversation there without taking it out of any place it is already in. The last entry, "All places…", opens the place switcher so you can pick any place, not only the ten shown.

## Why History has no Add to place item

The item only appears when at least one place exists. With no places there is nothing to add to, so the menu leaves it out rather than showing an empty submenu. Archived places are never offered.
