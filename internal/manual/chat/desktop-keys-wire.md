# Desktop keys for Next up, history and up a level

## Which key walks my waiting questions, and which steps back

Command J (Ctrl J off a Mac) starts the Next up walk through the questions waiting on you. Command [ steps back through where you have been, and Command ] steps forward again. Off a Mac the same two are Alt Left and Alt Right. While a Next up walk is open, the back chord returns you to where the walk began instead of stepping through history, and the forward chord does nothing until the walk has returned. With nothing waiting, Command J changes nothing.

## What does Command Up do, and what happened to Command I

Command Up (Ctrl Up off a Mac) goes up a level, to the parent place, but only on a place's Home and not while the cursor is in its composer. Inside a chat it keeps its older meaning: it moves to the previous message. Command I is retired and does nothing.
