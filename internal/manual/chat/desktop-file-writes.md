# Desktop file tab does not edit files

## Can I edit text in the desktop file tab

No. The desktop file tab shows the file. You can switch between Changes and File, and Open in hands the file to an editor on the engine's machine. You cannot type into the tab, and there is no save. Asking codeaf in the conversation can still change the file. That is the conversation, not a control on the file tab. Nothing is drawn for a save that does not exist.

## Can I rename a file from the desktop file tab

No. The desktop file tab cannot rename a file, and it cannot move one. Rename on a tab or a group renames that tab or group. It does not change the file's name on disk. Open in still hands the file to an editor. Asking codeaf in the conversation can still rename a file. That is the conversation, not a control on the file tab.

## Can I delete a file from the desktop file tab

No. The desktop file tab cannot delete a file. There is no delete control, and a file the engine did not send is not shown. Asking codeaf in the conversation can still delete a file. That is the conversation, not a control on the file tab.

## Does the desktop file tab save

No. The desktop file tab does not save. It reads the file the engine sends and does not keep a draft, a dirty mark, or a saved mark. A change made in an editor, or by the conversation, shows up when the tab reads the file again. Until that read, the tab keeps showing the text it already has.
