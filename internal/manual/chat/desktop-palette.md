# Desktop go-to palette

## How do I search for a place, or create one, in the desktop palette?

The go-to palette is a sheet over the current place with one field, "Go to a place, or create one", and a count such as "58 places" on its right. With nothing typed it lists Recent (the places you went to last, newest first, with how long ago) and then All, the whole tree. Typing replaces both with one ranked list of places whose name or path matches, so "cod soft" finds Software inside codeaf. If nothing matches, the list is a single row, Create “name”. The palette shows the places already loaded; it has no spinner and never waits on the engine.

## What do the keys do in the desktop go-to palette?

↑ and ↓ move through the rows, and → and ← open and close a branch of All while the field is empty (with text, they move the caret). ↵ opens the place in this window. ⌘↵ (Ctrl ↵ off a Mac) opens it in a new window. ⌘N (Ctrl N) makes a new place from the words typed. Esc closes the sheet and puts focus back where it was. The footer lists the three verbs. The palette does not move, rename or delete a place; it only goes to one or asks to create one.

## How does the desktop go-to palette look in a narrow window?

At 600 pixels wide or narrower the sheet takes the full width of the window instead of floating at 620 by 560. Long lists draw only the rows near the scroll position, so a graph of 200 places scrolls without slowing.
