# Grouping the selected desktop tabs

## Group the selected tabs with the keyboard in the desktop app

In the desktop app, ⌘-click tabs to select them (Ctrl-click on Linux), then press ⌘G (Ctrl+G on Linux). The selected tabs become one new group, standing where the first of them stood. The selection clears, and the new group's name opens for renaming straight away: type a name and press Enter, or press Escape to keep the default.

## What ⌘G does when no tabs are selected

With nothing selected, ⌘G groups the active tab alone into a new group, then opens the name for renaming. The Inbox tab never joins a group, so ⌘G there makes nothing.

## New group in the tab menu

Right-click a tab, then Add to group, then "New group…" (it shows ⌘G). It takes the same path as the key: if the tab is part of the selection, every selected tab is grouped; otherwise only that tab. The default name is "New group", or "New group 2" and so on when that name is taken.
