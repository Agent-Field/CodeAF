# Desktop web address row

## Desktop web address: URL selection, Enter and Escape

Click the web address field to select the whole URL. Type the new address and
press Enter to navigate. Escape restores the current page's address and leaves
the field without navigating. Only http and https pages open in a web tab;
addresses with passwords and other schemes are refused in the field.

Back and Forward use the page's history. Forward is disabled when the native
page reports no forward history. On platforms that cannot report history,
both controls stay available. Reload refreshes the page; while it loads,
Stop loading replaces Reload.

## Where did Open in browser and Start a conversation with this page go?

At window widths of 600 pixels or less, Open in browser and Start a conversation
with this page move into the Page actions menu (the three dots). Wider windows
show their icon buttons beside the address. Each icon button has a tooltip.
Open in browser sends the current URL to the default browser. Start a conversation
with this page opens an unsent draft; it does not send a message for you.
