# Using list and what a place knows

## What does the Using list show for what a place knows?

Open the Using chip on a conversation. The Instructions group lists each line that place knows, not one block of joined prose. Every line is labelled with the place it came from. A line you wrote says "you added". A line taken from a file names that file. A line learned from your answers says "Learned from N of your answers". When the bundle has no knowledge lines, the group still shows that place's instruction prose, labelled with the place.

## Where does a learned line show in the Using popover?

A learned line is a row in Instructions, under the Using chip. The words are the line itself. Under them is "Learned from N of your answers", and the place name sits at the end of the row. The count is the one the place recorded. A learned line with no count leaves that caption out.

## Why is a replaced line struck in the Using list?

When a newer line wins, the older one stays in Instructions, struck through, and says "Replaced" with the weekday it was replaced and "kept for 7 days". After those seven days it leaves the list. The model is not given the replaced line. A line with no replacement day is not struck and does not invent a date.

## Does Now also using change when a place knows something?

No. Adding a source still writes "Now also using <Place>: <source> · Undo" in the conversation, and Undo still takes back that change. The Using list's knowledge lines do not replace that note.
