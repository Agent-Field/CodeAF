# Desktop markdown links

## Why is a link in a desktop reply accent coloured?

In the desktop app, a link written in an assistant reply is drawn in the accent colour of the place, in Light and in Dark. The words are not underlined while you are only reading them. The accent colour is how you can see that the words are a link.

## When does a desktop markdown link underline on hover?

Point at a desktop markdown link and a line appears under the words, in the same colour as the text. Move the pointer away and the line goes away. Tab to the link with the keyboard and the same line appears, together with the usual focus ring. Clicking the link does not paint a fill behind the words.
