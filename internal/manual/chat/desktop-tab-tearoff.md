# Tearoff: dragging a desktop tab out of the strip

## What happens when I drag a tab out of the window

In the desktop app, drag a tab until the pointer is outside the window and let go. A new window opens on the same place, showing that tab. Its top-left corner is where you let go, including a display to the left of this one.

The tab stays in the first window's strip too. Both windows show the same tabs. If that tab was the one on screen, the first window shows the tab next to it instead. Another window that was already open on the same place keeps showing the tab it had.

Letting go while the pointer is still inside the window does not open one, even on empty space. Dropping the tab on another tab, a group or a split edge does not open one either: that drop is a reorder, a group or a split.

If the new window cannot open, the tab stays where it was and nothing else moves.

## Can I drag a pinned tab or the Inbox into its own window

No. A pinned tab stays in this window when you drag it outside. The Inbox stays too. A place's Home stays. In a browser there is no second window, so letting go outside does nothing there either.

## Does dragging a tab out of the strip stop what it was doing

No. The work keeps running. Dragging a tab out does not close it and does not stop it.
