# Desktop tab sets

## Why do two windows show the same tabs

Two desktop windows open on the same place show one tab set. Open a tab, close one,
pin one, or type a draft in either window and the other window follows. There is not
a second copy of the tabs. A window is a view of that place. Now has its own tab set,
and each place has its own; switching place shows the tabs you left there, and work
that was running keeps running.

## Where did the tabs I already had go

Tabs saved on this computer before places kept their own tab set are copied into Now
the first time Now has none. That happens once. The old copy is left where it was, so
nothing is deleted, and a later empty Now does not copy them in again. A place that
already has tabs is left as it is.

## Which tab is selected in each window

Each window remembers the tab it is showing, which pane of a split it is focused on,
and how far you had scrolled. The other window does not follow that. Close a tab in
one window and the other window, if it was showing that tab, moves to a tab that is
still open. Relaunching the same window shows the tab it was on.

## What happens to my tabs when the engine is offline

The window keeps the tabs you already have and you can keep editing them. Nothing is
thrown away because the engine cannot be reached. When the engine is back, the edits
are saved. Until then the other window cannot see them.

## What if both windows change the tabs at the same time

Both changes are kept when they are different tabs: a tab the other window just
opened stays, and a tab this window just opened is added. The window you are in
keeps showing its own tab when that tab is still open. If the same tab was edited in
both windows, the edit from the window that saved second is the one that remains.
