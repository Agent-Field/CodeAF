# Opening a chat from a parent Home

## Where does the desktop find the journal when a parent home shows a chat in a child place

A place Home lists chats that need you or are running in that place and in the places inside it. A row from a child place says "in" and that child's name, for example "in Config parser". Clicking the row, or focusing it and pressing Enter, opens that chat.

The parent Home does not repeat the chat's saved file. The desktop reads the file from the child place the chat is filed in, then opens the conversation in a tab. If that place does not say where the chat is saved, Home says it cannot be opened here.

## What happens when I click a live row that says in Config parser

The row opens the conversation named on it. The tab uses that conversation's title. The words "needs you" and "running" stay the ordinary text colour. Only the small mark is coloured: amber when it needs you, the accent while it is running.
