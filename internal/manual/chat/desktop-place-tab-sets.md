# Desktop place tab sets

## Are my desktop window tab sets saved when I switch places?

There is one saved tab set, and switching places does not change it. Places are libraries, not workspaces: going to a place opens its Home as a tab in the strip you already have, and no other tab is replaced, closed or moved. The engine keeps the tabs, groups, pins, splits and closed tabs once for every window. Windows share that set, while which tab each window focuses stays local to that window. Which tabs belong to which place is saved with each tab.

## Why does Now have no pinned Home tab?

No place has a pinned Home tab any more. A place's Home is an ordinary tab that opens when you click the place in the rail, and you can close it like any other. Now has no Home at all: it is the whole strip with nothing focused. All places is a separate view that can be opened in the strip.

## Where does a chat started from the Home composer open?

Sending from Home starts a conversation in that place and opens its tab after Home. Home stays a Home. Enter focuses the new conversation; Command Enter on macOS or Control Enter elsewhere opens it in the background.
