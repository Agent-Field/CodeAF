# Desktop task tab beside its conversation

## Can I put a chat and its task side by side?

Yes. Open the task as its own tab, then put that tab beside the conversation with Open in split.
One pane keeps the transcript. The other shows that task: the parent button, the task name,
Instructions and the work log. The panes share the saved conversation. They do not share which
task is open. Drilling into a task in one pane leaves the other pane where it was. If the chat
was already showing that task, opening it as a tab returns the chat to the transcript so the
two can sit side by side.

## Does opening a task in a new tab change the conversation?

Only when the conversation is already showing that task. A conversation on the transcript stays
on the transcript. A conversation showing a different task stays on that task. Opening the task
it is already showing hands that view over: the conversation returns to the route under the
drill, and the new tab takes the task. The task tab opens in the background and the conversation
tab stays selected. Modifier-click, middle-click and Open in new tab all do this. A plain click
still opens the task inside the conversation tab.

## If I go back in a task tab, does the chat beside it change?

No. Back on the task's parent button does not copy that task into the chat beside it, and it
does not clear a route the chat is showing on its own. Each pane keeps the route stored on
its own id. The composer is still one draft for the conversation.

## I opened a task inside the chat and then opened it in a new tab

The chat was already showing that task, breadcrumb and all. Opening that same view as its own
tab hands it over. Expand tasks, Open in new tab, a command-click and dropping the chat tab
onto a split all do this. The new tab shows the task. The chat goes back to the transcript
and the breadcrumb is gone. Back in the new tab does not return to the conversation: that
tab's history starts at the task, so Back cannot land on the transcript. Opening a task the
chat is not showing leaves the chat where it was. From the transcript, Expand tasks still
opens the tasks table.
