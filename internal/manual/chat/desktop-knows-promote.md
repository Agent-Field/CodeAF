# What a place learns from answers and memory

## What happens when I answer the same way three times

Answer one kind of question the same way three times in one place, with no different answer of that kind in between, and the place gains a knowledge line. The line's text is that answer, taken from the third time you gave it. Its source is `learned`, its answer count is 3, and the source caption is "Learned from 3 of your answers". A fourth answer the same way does not add another line. A different answer in between starts the count over, so two the same, one different, then two the same again does not learn anything.

"Use tabs." and "use tabs" count as the same answer. Two kinds are counted apart: three Allows on a permission do not learn a pricing choice you only answered twice.

Three answers the other way add a new learned line and strike the earlier learned line of that kind, including on the same day. The struck line stays in the record so you can see what changed. A line you wrote yourself is not struck by this count. Passing the same answer history again does not add a second copy.

## Does a decided memory show up in what a place knows

A memory the store decider settles for a place becomes a knowledge line when the settled memory has a title and the caller names the place. The decider's answers are add, refine, replace, and skip. Its own words `update` and `supersede` are refine and replace.

Add writes the settled text as a new line whose source is `said-in-chat`, keeping the chat and the time when those were supplied. Replace writes that new line and marks the older line replaced, unless both lines are your own words from the same day, in which case the place asks once and leaves the older line unstruck. Refine updates the text of the line the decider named and keeps the source that line already had, so a line you wrote stays a line you wrote. Skip writes nothing. A memory with no title, a blank place, or a decider that cannot answer writes nothing. A replacement aimed at a line this place does not hold is a skip. This does not pick a place when a chat is in several, and it does not write or retire the session memory row.

## Can I undo a line the place learned

The write returns the place graph's Undo receipt. Undo removes a line that was added and restores a line that was refined or struck. The receipt belongs to the running store and does not survive a restart.
