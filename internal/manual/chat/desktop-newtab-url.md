# New tab web address

## Can I paste a URL into the new tab to open a web page

Yes, in the desktop app. Paste or type an http or https address, or a bare site with a dot and no spaces such as pkg.go.dev/encoding/json, into a new tab. The first row becomes "Open" followed by the site, and Enter turns this tab into a web tab at that address. The row below still asks the same words as a question, one arrow key away.

Anything else stays a question: words with spaces, and addresses with another scheme such as ftp. Where web pages cannot be shown, the Open row is not drawn and the address is asked as a question like any other text.
