# Desktop window shell

## Which place opens when I launch a desktop window?

The main desktop window returns to the place it last showed. A new window opens
on its requested place, or Now when no place was requested. Each window remembers
its own place. A missing or archived place returns to Now after the engine reads
the places graph. Opening All places shows its tab in Now.

## Why does an inactive desktop window lose its glass frame?

Only the rail and tab strip use the translucent frame; conversation cards stay
opaque. An inactive desktop window uses the solid frame. Reduce Transparency or
Increase Contrast also makes the frame solid. Linux and browser windows use
frame blur when supported; native macOS and Windows use their window material.

## Where did the desktop Activity page go?

The Activity page is removed. Settings opens as a workspace tab from the bottom
rail row or Command-comma (Control-comma off a Mac). Theme lives in Appearance
in Settings. Design system is available only in development builds.
Command-K (Control-K off a Mac) focuses the New-tab field.
