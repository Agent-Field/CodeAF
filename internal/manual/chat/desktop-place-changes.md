# Place change lines

## Now also using a place, with Undo

When you file an open conversation under a place in the desktop app, that conversation draws one line straight away: "Now also using Release: brand-voice.md · Undo". It names the sources the place newly brings to the chat, three at most and then "N more". A source the chat already had from another place is not named. Undo takes the filing back. Only the conversation you filed shows the line; every other open conversation stays quiet. The same line is kept in the conversation's record, so it is still there after a reload.

## No longer using a place

Taking an open conversation out of a place draws "No longer using Release" with Undo. It names no sources. A conversation that is not open on screen shows no line; the record of the change is what it reads at its next turn.
