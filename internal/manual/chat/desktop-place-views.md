# Desktop place views and other homes for a chat

## What are Views on a place Home and how do I clear a view

"Views" on a place Home lists the views the engine supplies for that place. Press a view to show only its chats. Press the same view again to clear that filter. A view does not create a sub-place or move a chat; it is another way to read the existing list.

Views can arrange chats by month or kind of work. A place with at least fifteen chats can receive month views. If the engine supplies no views, there are no view chips. Changing a view never adds sources or changes the place's instructions.

## Why does my chat say also in another place

An "also in" mark means this chat belongs in another place too. When the engine supplies its main place's name, the mark reads "also in" followed by that name. This is the same saved conversation, rather than a copied chat.

A conversation can earn additional homes from both where it started and where it ended. The start is its title and first message. The end uses its latest two later user messages and latest assistant reply, shortened to about 600 characters; a chat with only its opening message has no separate end. A place must be a clear match and close to the best match at either end to qualify. There is no fixed cap on earned homes. A change of subject can therefore earn another home while preserving the recorded main place; changing that main place is an offer.
