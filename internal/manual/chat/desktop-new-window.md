# New window on Now

## Does command N open another codeaf window on Now?

In the desktop app, command N on macOS and Ctrl N on Linux open another window on Now.
File, then New Window, does the same thing. The window you were already in stays on its place.
Opening a window does not start another engine.

Inside Go to, that same chord creates a place instead of a window. The sheet says "new place".

## Why does Ctrl N stay with the browser?

A codeaf page opened in a plain browser does not take command N or Ctrl N. The browser keeps
its own new window. codeaf does not open a tab for you and does not switch this window to Now.
There is no File, New Window item in the browser.

## What if opening a new window is refused?

The desktop app says why, in one toast. When the shell sends no sentence, the toast says
"Could not open a window". The window you are in does not change.
