# Desktop place from a folder

## Make a place from a folder or repository — drop a folder on the rail

Dropping a folder on the desktop app's rail makes a place named after the folder, with
that folder as its first source and a colour chosen for a new top-level place. A folder
inside a git repository makes the place for the whole repository, named after the
repository's root folder, and the repository is its source.

Dropping the same folder again does not make a second place. It opens the one that
already lists that folder first. A folder codeaf will not hand to a chat, such as a
credentials folder, or one that is not on the disk is refused with a sentence.

If a top-level place already has that name for some other purpose, the drop is refused
rather than renamed.

## Move the matching tabs into the new place

After a folder becomes a place, the desktop app offers the conversations that already
ran inside that folder and are filed in no place, as "Move matching tabs". Accepting
files them in the new place with one step; declining leaves them where they are. Chats
already filed in a place are never offered, and nothing is moved without that step.
