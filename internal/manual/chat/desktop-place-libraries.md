# Desktop places are libraries

## Does clicking a place in the desktop rail replace my tabs?

No. Places are libraries, not workspaces. There is one tab strip, and it never swaps when you go to a place. Clicking a place in the left rail opens that place's Home as a tab in the strip you already have, right after the tab you are on, and focuses it. If that place's Home is already open, the rail click brings that tab forward instead of opening a second one. Every other tab stays exactly where it was, with its drafts, groups, splits and running work. Command+P then Enter, and the Now row, work the same way; Now opens nothing and shows every tab.

## What is Focus on a place in the desktop app?

Focus filters the tab strip to the tabs that belong to one place, so you can work inside a place without the rest of the strip. Turn it on with the Focus button that appears when you hover a place row in the rail, or by Command-clicking (Control-clicking on Linux) the row. While it is on, the frame takes the place's tint, the strip shows a chip that reads "Focus · <place>", and the strip, the tab keys and Command+1 to 9 walk only the tabs in that place. Nothing is closed, moved or regrouped: Focus is only a view.

## How do I turn Focus off in the desktop app?

Click the chip in the strip, press the place's Focus button again (or Command-click the row again), or click Now in the rail. Every tab comes back in the order it had. Going to a different place from the rail also ends the Focus, because the Home you asked for belongs to the other place. Closing the place from the rail ends it too, and closes no tab.

## Which tabs belong to a place?

A place's Home belongs to that place. A tab you open while Focus is on a place belongs to it. A chat you open from a place's Home opens as a new tab beside the one you are on and keeps that place. A tab can belong to several places at once, and a tab that belongs to none shows only when no place is focused. If you start a new chat while Focus is on a place, it is filed in that place at its first message.

## How do I add a tab to a place in the desktop app?

Drag the tab from the strip onto a place row in the left rail. The tab joins that place, so it appears when that place is focused. Nothing moves: the tab stays where it was in the strip and keeps every place it already had, so dragging adds and never takes away. A tab that holds a saved chat also files that chat in the place with the engine, and the toast offers Undo. There is no drag that removes a tab from a place.

## Which place does the rail highlight in the desktop app?

The place of the tab in front. Select a tab that belongs to a place and that place's row reads as the open one; select a tab that belongs to none and Now does. When a tab belongs to several places and Focus is on one of them, that one is highlighted. The window title follows the same place.

## Limits

There is no per-place tab set any more: tabs saved under a place by an older version are not merged into the strip. With the rail hidden the Home tab is an ordinary tab, not a place switcher: use Command+P, the Control (Alt on Linux) number keys, or reveal the rail. Closing a Home tab closes only that tab.
