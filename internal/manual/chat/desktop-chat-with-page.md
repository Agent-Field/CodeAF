# Ask about a web page

## How do I start a conversation about this web page?

On a web tab, the button named "Start a conversation with this page" (the chat-plus mark) opens a new conversation immediately after that web tab and focuses it. The page's address and title are already in the composer, as a link, and nothing has been sent. You can edit the words before you send.

## Does chat-plus send the page?

No. Chat-plus does not send. The new conversation stays on the composer, with the page's address and title attached, until you send it yourself. Closing the web tab does not send it either.

## Does codeaf read the page body?

No. codeaf does not read the page body, and it does not fetch the page to attach it. The attachment is the address and the title the page already reported. When the desktop app has a picture of that page, the picture is attached too. The words of the page are not.
