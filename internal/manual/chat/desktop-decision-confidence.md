# Desktop decision confidence

## Why did it allow go test without asking me?

A place that is already deciding can allow a command on its own when it is sure
enough from what you have already done here. The sure figure comes from the
history of that same kind of question about that same command in this place,
and from a line in what the place knows when that line supports the answer.

Six allowances of `go test` out of six asks is 97. The reason is the sentence
"You allowed go test here 6 times. Reversible." A shorter run is not treated as
a full sample: fewer than six asks stay under 90, which is the default. A mix
of allowances and refusals also stays under 90. One matching knows line is 92,
and the reason is "matches what Marketing knows" with the place's own name.
When both exist, the higher figure is the one used.

The model is not asked for this number. A separate judge runs only when the
history is still too thin for the place's threshold.

## How sure does a place have to be before it decides?

The default is 90. The place menu's "Decision confidence…" sets it per place,
from 50 to 100. At 97 the place may decide; under the number you set, it asks
you or passes the question to a parent place. A brand-new place is still
learning, so a high figure there is a proposal you confirm, not a decision it
takes alone.

Nothing measured draws no percent. A zero is not a low score you can read; it
is the absence of one.

## Will it decide something I cannot undo?

An irreversible question always comes to you. Whatever the history or the
knows lines say, the figure is held under 50, which is under every confidence
setting the menu allows, so the place never decides it. The reason ends with
"Irreversible." Something costly can still be decided when the figure clears
the threshold, because it can be undone. Only irreversible is held back.
