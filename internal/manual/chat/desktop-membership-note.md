# Desktop membership notes

## Why does the chat say Now also using or No longer using?

A Places membership change leaves the engine's own line in the conversation. An addition can name new sources, for example “Now also using Release: brand-voice.md”. A removal says “No longer using Release”. The recorded text survives replay. The layers mark and muted text identify a context change, rather than an assistant reply.

## Undo the place change from the conversation

The note's Undo uses the receipts recorded with that change. It takes back that membership change, rather than whichever change happened most recently. While the request runs, Undo cannot be pressed again. After success its action disappears and the Places graph refreshes. A refused Undo shows the engine's explanation and leaves the action available. A note without receipts, or outside a connected Places shell, has no Undo action.
