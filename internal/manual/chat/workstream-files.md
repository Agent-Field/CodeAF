# Files — a workstream's shared drive

## what Files is — documents, canvases, uploads, links and repos in folders

Files is a workstream's shared drive: everything worth keeping, in folders, made by people or by agents. It replaces the separate Pages, Sources and Canvases tabs. A file is one of five kinds, plus folders and shortcuts:

- **Document** — a page you write in together (the same editor, comments, suggestions and history pages always had);
- **Canvas** — a canvas made inside the workstream;
- **Upload** — a file from your computer (at most 25 MiB on an organization's server);
- **Link** — a web address;
- **Repo** — a connected repository, `owner/name`.

Every file shows who made it (a person, Afi, or a chat's name), the task it came from, and when it last changed. Every workstream starts with a **Decisions** document. Agents read every file in the workstream and in the workstream it sits inside.

## where my old pages, sources and canvases went — nothing was lost

The first time a workstream's Files is opened, everything it kept before is folded in, once, and nothing is copied or lost: each page becomes a document (a page that held other pages also becomes a folder holding them), each source becomes a link, a repo or an upload, each canvas made inside the workstream becomes a canvas file, and a workstream with no decisions page gets a Decisions document carrying the decisions it already had.

## New, search, sort, folders — making and finding files

**New** offers Document, Canvas, Folder, Upload a File, Add a Link and Shortcut to a File Elsewhere. A new document or canvas is made in the open or selected folder and opens as a tab. A new folder appears with its name ready to type: Return keeps it, Escape removes it. Files can also be dropped onto the list from the computer; dropped on a folder, they go into it.

The search box finds files by name and by what they say. A click on a column name (Name, Kind, Made by, Changed) sorts by it. Folders nest without limit and fold open in place.

## select, open, rename, move, delete — the right-click menu and keys

One click selects a file and shows its facts (kind, where, who made it, the task it came from, the tasks that use it, last change, versions, open comments); Space shows them too. A double click or Return opens it as a tab. Shift-click selects a run of rows, Command-click adds or removes one; with several selected, a bar offers Move to, Copy links and Delete — only what applies to every selected row.

The right-click menu: Open, Open Beside, Rename (in place, in the row), Move To, Copy Link, Add a Shortcut in Another Workstream, Show Versions, Ask Afi About This (adds the file to what Afi is looking at), Delete. A folder has the same menu without Show Versions. Dragging files onto a folder moves them, with Undo for 5 seconds. Moving a file never breaks a task, shortcut or link that points to it.

## delete a file, Recently deleted, restore — how long deleted files are kept

Delete moves a file to Recently deleted for 30 days, with Undo for 5 seconds. Deleting a folder takes everything inside it, and restoring the folder brings exactly those files back. A restored file goes back to its folder, or to the top when that folder is gone. After 30 days a deleted file is let go for good, with its document's words and versions.

## shortcuts and a parent's files — a file from another workstream, read-only

A shortcut shows a file that lives in another workstream without copying it: there is still one file, changed in one place. You can only make a shortcut to a file in a workstream you can see.

A workstream inside another one shows its parent's files in a "From <parent>" section, read-only there.

## can Afi change my document — suggestions, accept and reject

Afi and chats change a document by suggestion: the old words struck through, the new ones underlined, with Accept and Reject. Anyone in the workstream can accept or reject. An agent edits directly only a file it made that no person has edited yet. A comment never makes Afi act: to have Afi change the text, ask in Afi's pane, and the change arrives as a suggestion. Changing a file flags the running tasks that use it.
