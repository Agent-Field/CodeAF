# Empty places in the desktop

## Why does my desktop place say Nothing here yet?

A place without chats, child places, sources or recorded activity says:
“Nothing here yet. Start a chat below, drag chats in from anywhere, or drop in what this place should know.”
Start a chat with the composer below, or drag chats into this place.

## How do I add files or links to an empty desktop place?

Choose Add files or links to open the place's source dialog. In the desktop app,
Choose files opens the native file chooser. You can also paste a path or a link.
Added sources belong to this place. The browser offers the path or link field;
choosing from disk needs the desktop app.

## How do I write instructions in an empty desktop place?

Choose Write instructions. The instructions editor opens and takes focus.
Blur saves the prose; Escape restores the saved text. Changes are paused while
codeaf cannot reach the engine.

## Why does my empty desktop place say Uses Marketing's context?

An empty place can still inherit sources from its parents and grandparents.
The dim line names the ancestor and its real sources, for example
“Uses Marketing's context: brand-voice.md, codeaf.dev”. An ancestor with no
sources adds no line. If the sources cannot be read, nothing is guessed.
