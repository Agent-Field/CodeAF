# Organize places

## Where is Organize now

Organize now is in Settings, under Places organization, below the choices for how codeaf offers places. Pressing it asks codeaf to organize your places. If one is already going, the press joins that run. It does not start a second one.

## Add to what's there or start fresh

The choice beside Organize now is how the run treats the places you already have.

Add to what's there is already selected. It keeps every place as it is and files what is not placed yet.

Start fresh rebuilds, then asks you before anything structural changes. Places you made stay together.

Nothing structural changes until you accept the review.

## What it says while organizing places

While places are being organized, one quiet sentence names the step. It reads Reading and a chat count while it is reading chats, Grouping while it groups them, Naming with how many names are done while it is naming, and Checking while it checks. A step it cannot name adds no sentence. Cancel stops the run. A cancelled run changes nothing.

## Review the plan and uncheck a change

When the run has a plan, a sheet titled Review opens. The summary is the sentence the run wrote. Each change is a row. Uncheck a row to leave that change out. Accept applies the rest as one change. Not now leaves things as they were. Escape closes the sheet without deciding. Review opens it again.

## Undo organizing places

After you accept, Undo puts that one change back. It uses the one receipt the accept returned.
