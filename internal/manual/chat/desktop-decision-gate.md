# When a place answers a question

## Does a place decide a question before I see it

When a question is raised, the place is asked before the question is shown. Irreversible work always comes to you. A place set to always ask you, and a kind set to always ask, also come to you. A judgement, a confirmation, a landing, and a clarification come to you, and so does any question the policy forbids a place to answer.

A place that is already deciding, and sure enough for its threshold, answers the question once. The default threshold is 90. You do not see a card. The answer is recorded, and a receipt is left: "Allowed automatically by Marketing · reason · Why?" for a permission, or "Decided automatically by Marketing · reason · Why?" for anything else. Something costly can still be decided when the figure clears the threshold, because it can be undone. A question that was already withdrawn is never decided. Asking the same question again does not decide it a second time.

## Why is the choice already selected while a place is learning

A place that is still learning does not answer alone. The question arrives where it would have, with the place's choice already selected, how sure it is, and why. The question is marked with that place and the count toward 20, such as 14 of 20. Agreeing means you chose that proposed key. The place does not pass the question up to a parent while it is learning, even when that parent could have decided.

## Why did a parent place allow this

When the place is deciding but the figure is under its threshold, the question is passed up the place graph. A parent that is deciding and sure enough answers it once, and the receipt names that parent. When no place can decide, the question comes to you.

## Why did it still ask me

It still asks you when the work is irreversible, when the place or the kind is set to always ask you, when the policy forbids a place to answer, or when no place was sure enough. A question that was withdrawn is left alone. With no place wired to decide, every question comes to you, the same as before.
