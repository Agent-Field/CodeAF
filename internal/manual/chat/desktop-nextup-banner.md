# Next up banner

## Desktop nextup banner

A blocking item in another conversation raises a banner. It slides out of the frame pill. The amber dot means it needs you. The first line is the ask, for example "Allow 3 git actions?". The second line names the conversation, for example "Config parser · holding up 2 tasks". ⌘J sits on the right. On Windows and Linux that hint reads Ctrl J. A press on the banner starts Next up at that item.

## It folds into the pill after 4 seconds

The banner folds back into the pill after 4 seconds. The timer pauses while the pointer is on it or while it has keyboard focus, and continues when you leave. A press also folds it, because Next up has started. With reduced motion it fades and does not slide. A screen reader hears the banner once, when it appears.

## When the banner stays off

An item the engine marks as not blocking does not raise this banner. Running, done and failed work do not raise it either. Nothing is drawn when there is no ask. The second line is left off when the engine did not send one.
