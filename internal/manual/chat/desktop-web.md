# Web pages in the desktop app

## Opening a web page in the desktop app — the page stays in the card

In the desktop app a web tab shows the page inside the card, on its own sheet.
Back, forward and reload move through that page. The page can be an http or
https address. A file, a codeaf page, or any other kind of address is refused,
and the address field says so. The page cannot run codeaf commands, and it
cannot download a file or use the camera, microphone or location.

Outside the desktop app the same tab says "Web pages open in the desktop app"
and offers Open in browser.

## Keyboard shortcuts while a web page is focused — new tab, close tab, the address

While the page has the keyboard, the app chords still work. ⌘T (Ctrl+T off a
Mac) opens a new tab. ⌘W (Ctrl+W) closes the tab. ⌘L (Ctrl+L) moves to the
address field of that page. On a Mac these are the app menu. Off a Mac they are
window shortcuts, so they still run when the page has the keys. The page does
not receive those three chords.
