# Desktop rail rows

## What does the number next to Now in the desktop sidebar mean?

In the desktop app's left rail, the Now row shows a small grey number: how many things are running across everything in Now. When nothing is running the number is not drawn at all; it never reads 0.

If something needs you, an amber dot appears at the right end of the row. Hover the dot and it says how many need you in words, for example "2 need you in Now". A failure draws a red dot instead. Running work alone draws no dot.

## Is there an Inbox row in the desktop sidebar?

No. The desktop has no Inbox row and no Inbox tab. Anything that needs you in another conversation is counted by one pill at the right end of the tab strip ("N need you elsewhere"), and the pill is hidden when the count is 0. The rail's Now row only carries its own running count and attention dot. Right-clicking the Now row opens nothing.
