# New tab start rows

## How do I open a new terminal from the new tab

On a new tab, Start shows New terminal with ⌃` on a Mac and Ctrl ` elsewhere, while a terminal can be opened. Choosing that row turns this tab into a terminal and starts a shell. It does not send a message to the model. When a terminal cannot be opened, that row is not shown.

⌃` itself, from a conversation, opens a shell under the conversation in front. It is a separate key from the row.

## What does command O do

⌘O on a Mac, or Ctrl O elsewhere, opens a New tab, or focuses a New tab that is already open. The line under the field then reads "Type part of a file name." Choosing the Open file… row does the same thing and keeps you in that field.

Type part of a name and the files that match are listed. Choosing one opens that file in this tab. There is no system file window, because the files are on the machine the engine runs on.

A window that is already open, such as All tabs, keeps the chord. A text field that already holds words keeps it too, so it does not leave what you are writing.

## Type part of a file name

After Open file… or ⌘O (Ctrl O elsewhere), the line under the new-tab field reads "Type part of a file name." Type part of a name and the files that match are listed. Choosing one opens that file in this tab. There is no system file window, because the files are on the machine the engine runs on.
