# Desktop live guess: a suggested place while typing

## What is the suggested place arrow beside my draft

Until the first reply settles, the desktop composer can show an arrow and a place name, such as "→ Desk app". This is a guess about where your draft belongs, rather than a saved filing. It uses the places you already have. The folder and a recently opened place can influence it.

The guess is calculated locally without asking a model. Typing waits 300 milliseconds before asking for a new guess. Every edit hides the old guess immediately. A response that takes more than 20 milliseconds is hidden; no stale name stays on screen. An empty draft or no usable answer draws nothing.

## How do I change the suggested place for my first message

Click the arrow and name to open "Change suggested place", then pick a place. That choice stays local until the first reply has settled. Typing or changing the guess alone does not file the chat. The choice can be applied only to a saved chat.

The ordinary filing offer after a reply remains the engine's decision when you have not chosen a place yourself. "Guess a place while typing" in Places organization controls whether guesses are enabled.
