# Desktop queued message actions

## How do I edit a queued message in the desktop app?

Click a queued message's text to edit it inline. Enter or Save keeps the change;
Escape cancels it. The Edit button and the row menu's Edit do the same thing.
Only messages still waiting in the engine queue can be changed.

## How do I move, send now or remove queued messages?

Right-click a queued row, or focus it and press Shift+F10, for Edit, Move up,
Move down, Send now and Remove. Move up is disabled at the first position;
Move down is disabled at the last. Alt+Up and Alt+Down also move the focused
row and keep focus. Moving below the two visible rows expands the queue.

Send now delivers that queued message immediately through the engine. Remove
takes it out of the engine queue so it will never run. If it has already been
sent, the engine refuses and the composer says "that message has already been sent".

On touch screens dragging is disabled. The row's actions stay visible, and the
three-dot menu offers the same moves and Send now.
