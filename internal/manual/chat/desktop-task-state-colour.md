# Desktop task state colour

## Why is an incomplete desktop task marked with a red dot?

In the desktop Tasks panel, an incomplete task has a still red dot, 6 pixels
wide and tall. The dot uses the failure colour for the current Light or Dark
appearance. The task title stays in ordinary ink; the state does not colour
the words or add a stripe to the row.

## What do the colours on desktop task dots mean?

Running work has an accent dot. Work waiting for you has an amber dot.
Failed or incomplete work has a red dot. These marks describe the task state
reported by the engine; they do not invent progress or change the task.
