# Desktop button sizes

## Why are desktop buttons different heights?

The desktop's shared button has a 28px default control size. It also provides
an explicit 30px tray size for tray answers and History's Best match action.
The size changes the minimum height; the primary, raised, quiet, ghost and
danger appearances keep their shared styling. Individual screens choose the
size, so this does not enlarge every button in the app.

## Can I make desktop buttons taller?

There is no button-height preference. The screen chooses the shared control's size.
Disabled and loading buttons keep that size; a loading button cannot be pressed.
