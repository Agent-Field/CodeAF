# Desktop web page identity

## Why did my web tab title change, and does Rename tab win?

A desktop web tab follows the page's title. Rename tab gives it your own name;
subsequent page titles cannot replace that name, including after a relaunch.
Navigation updates the page's address and the tab's page summary even when the
page title stays the same.

## Does a web tab remember the address after a relaunch?

The web tab saves its latest http or https address. Relaunch opens that address.
Back and Forward follow the native page's history flags. Where the platform
cannot report those flags, both buttons remain available. A saved address does
not promise that the platform restores the previous navigation history.

## Where is the web loading spinner, favicon or site letter?

Loading draws a 2px line across the top of the content card. The tab stays quiet:
no spinner, progress count or loading badge. Until the engine fetches a site's
favicon, the tab shows a letter from the site name. An unavailable favicon keeps
the letter. Web pages themselves open only in the desktop app; a browser window
offers Open in browser instead.
