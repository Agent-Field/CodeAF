# Create a desktop place inline

## How do I create a new desktop place with a name and tint?

Click **New place** in the desktop Home's Places grid (or **Name a place** on first launch). The tile becomes a name field and five tint swatches: tide, rose, sage, sand and iris. The least-used tint among the grid's active places is selected; ties follow that order. Choose another swatch by clicking it or using the arrow keys in the tint picker.

Type a name and press Enter to create. The hint reads “↵ create · Esc cancel”. A blank or whitespace-only name cannot create a place. Names already used by a sibling are refused. The engine must accept the creation before the field closes; a failed write keeps the draft.

## How do I cancel inline desktop creation with Escape or choose its parent?

A place created from a place's Home is inside that place. From All places, it is a top-level place. Press Escape in the name field or tint picker to cancel. The New place tile returns and receives keyboard focus. Canceling makes no engine change.
