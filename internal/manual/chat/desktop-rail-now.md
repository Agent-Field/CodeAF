# Desktop Now row

## How do I switch the desktop window to Now and my unplaced tabs?

Click Now in the desktop rail. This window switches to the Now workspace, restores its unplaced tabs and uses the graphite frame tint. Tabs saved in a place stay there when you leave it. Switching does not stop running work.

## How do I command-click or middle-click Now to open a new window?

In the desktop app, Command-click (Control-click on Linux) or middle-click the Now row opens a new window on Now. The current window keeps its place and tabs. Now has no right-click menu.

## What does command-click Now do in a browser?

In a browser, Command-click or Control-click Now switches this window to Now, just like a plain click. The row offers no native new-window action. Middle-click has no new-window action in a browser.
