# Desktop window

## Does the desktop side list still have an Inbox row

No. The side list is Now, the places you have open, and All places. There is no Inbox row. A question waiting in another conversation is counted on the frame pill at the right end of the tab strip ("1 need you elsewhere"). The pill is absent when that count is zero. Questions that were already waiting when the window opened stay on the pill and do not raise a banner.

## Where did the desktop Inbox row go

It was replaced by Next up. The frame pill is that count, and ⌘J (Ctrl J on Linux) walks the questions. The banner under the pill is only for a blocking question that arrives after the window has opened.

## What does the desktop window remember when I go back

The window remembers tab changes, place switches, and opening a task inside a tab. ⌘[ goes back and ⌘] goes forward. Off a Mac those are Alt Left and Alt Right. Back returns to the place, the tab, and, when you had opened a task, that task.
