# Desktop link chips

## How do I open a desktop link chip in a web tab?

A plain click on a link chip opens its URL in your default browser.
Command-click on a Mac, Control-click elsewhere, or middle-click opens the
URL in a codeaf web tab. The new web tab takes focus. When native web tabs are
unavailable, the same gesture opens the default browser instead.
Prose links with their own words use these same actions.

## How do I copy a desktop link chip URL?

Right-click a link chip and choose "Copy link" to copy its full URL.
With the link focused, Shift+F10 opens the same menu. Prose links offer the
same menu. Copying does not open the URL.

## How do I see the full URL tooltip on a desktop link chip?

Hover over the link chip for 500 milliseconds to see its full URL in the
shared tooltip. Keyboard focus also shows the tooltip. Pressing, scrolling,
leaving the link, or Escape dismisses it. Touch does not show a tooltip.
Moving between links while a tooltip is still warm shows the next tooltip
immediately.
