# Dropping a folder on one chat

## Add a folder to only this conversation

Dropping a folder on a conversation in the desktop app refers it to that conversation alone, as a folder the person named. It does not add a source to the place the conversation belongs to. A folder inside a git repository is snapped to the repository root, and the folder you dropped is kept beside it. A relative path, a path that does not exist, or a file is refused with a sentence saying why.

## Add a source to a place instead

To make a folder, repository, file, link or conversation available to every chat in a place, add it to that place's sources. Only http and https links are accepted, and a link with a password in it is refused. Adding the same source twice is refused as already there.
