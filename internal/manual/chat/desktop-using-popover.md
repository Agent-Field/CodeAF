# Desktop Using popover

## What is in the desktop Using popover?

Press the Using chip in the conversation header to see Places, Instructions,
Sources and Policy. Only information returned by this conversation’s engine is
shown. An unknown or empty group draws nothing. Ancestors say “· inherited”.
Instructions show each place’s current knowledge lines, including their source
and recently replaced lines. Sources show the originating places, and unavailable
or refused sources retain the engine’s explanation. A muted “N sources trimmed”
line counts sources left out for room; those sources are not given to the model.
Policy explains the engine’s decision, for example “Release wanted Flash · codeaf
decided”. A setting waiting for the next message is not described as already in use.

## How do I add this conversation to a place from Using?

Press “Add to a place…” in the desktop Using popover and pick a place. Places the
conversation already directly belongs to are excluded. This adds membership;
it does not remove the conversation from another place. Cancelling the picker
changes nothing. The engine applies changed place context from the next turn.

## Can I drop files on the desktop Using popover for this chat only?

Drop files on the Using popover to put them in this conversation’s attachment
tray. They are sent with your next message, through the same transport as files
attached in the composer. This does not add sources to any place, change place
membership, or start a turn. Repeated drops add to the tray. Remove an attachment
from the tray before sending if you do not want it included. The existing limits
apply: 10 MB per picture and 20 MB total attachments; a refusal names the file.

## How do I close the desktop Using popover on a small window?

Escape closes the popover and returns keyboard focus to its Using chip. A press
outside closes it. At widths of 600 pixels or less it is a bottom sheet; otherwise
it is a 380-pixel popover kept inside the window. Long lists scroll within it.
