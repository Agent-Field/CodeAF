# Where a chat lives

## Why is this chat in the broader place instead of the smaller one

Organize puts a chat in the smaller place only when that place is clearly a better home than every place above it. A chat that is only a little closer to the smaller place stays with the broader one. The broader place is still its home. The smaller place is there for the chats that clearly belong in it.

Two chats can share the broader place while only one of them goes into the smaller place under it. Staying with the broader place is a home, not a leftover.

## When does a chat stay in Now instead of a place

A chat stays in Now when no place is close enough to be its home. Now is not a place. The chat is not filed, and it is not counted as belonging to a place. A chat that cannot be compared with the places stays in Now as well: there is no position for it, and a missing position is not a home.

A later chat can still be filed. This one waits in Now until a place is actually close enough.

## Does organize put every chat in the smallest folder

No. Chats about the same thing sit together, and that group can sit inside a broader one. A chat lives at the level that fits it, which is often the broader place. The smallest folder is used only when it is clearly the better home. Otherwise the chat stays with the place above it, or in Now when nothing is close enough.
